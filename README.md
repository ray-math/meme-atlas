## 기록 원칙
- 뜻, 배경, 실제 사용 용례, 주의점, 출처와 확인일을 남깁니다.
- 실제 용례에는 짧은 인용, 작성자·매체, 날짜와 원문 링크를 붙입니다. 미확인 용례는 만들어 채우지 않습니다.
- 최초 원작자나 원본을 모르면 미확인으로 표시합니다.
- 오래된 밈의 재유행과 새로운 밈을 구분합니다.
- 이미지·영상·기사 전문을 복제하지 않고 원문 링크를 사용합니다.
- 출처가 유료 영역이면 확인하지 못한 내용을 추정해 채우지 않습니다.
- 자동 업데이트는 아직 설정되어 있지 않습니다.
