# 100항목을 향한 소규모 확장 시험

수량보다 정확성을 우선하며 56개에서 10+10+10+10+4 묶음으로 진행한다. 새 항목은 한국 생성/독자 한국식 변형만 검토한다. 기존16의 별도 범위검토는 그대로 유지하므로 전체 숫자가 곧 한국 원작 인증 숫자는 아니다. main·주간 자동화·PR 제출은 변경하지 않는다.

## 5회차: 56 → 66
- 영화·방송 표현10개 추가. 일반 방언·일상문장 자체와 영화에서의 밈 확산을 구분했다.
- 독립 편집검토 뒤 모히또/몰디브의 부정확한 '두 고유명사' 설명을 수정하고 방송 태그로 통일했다.
- 구조검사·45개 단위검사 통과, 같은 입력 재실행 추가0.

## 확장 중 발견한 도구 개선
- 최종 작은 묶음도 처리하도록 입력을 1~10개로 제한했다. 빈묶음·11개 이상은 거부한다.
- 전체 사전의 YAML 별칭과 제목을 정규화해 서로 다른 항목 간 충돌을 검사한다.
- '모방'으로 손민수가 검색되지 않던 누락을 확인해 한 줄 요약뿐 아니라 뜻풀이 영역도 검색하도록 고쳤다. 응답에는 검색용 전체텍스트를 노출하지 않고 제목·요약·경로만 반환한다.
- [분야·소재별 목록](../collections/topics.md)을 생성해 GitHub에서도 태그별로 탐색할 수 있다.
- 배치 staging 단계에서 검색 인덱스와 분야목차를 함께 갱신하므로 본문만 추가되고 파생자료가 뒤처지는 경로를 줄였다.

## 한계
기계검사 성공은 내용 사실성을 인증하지 않는다. 직접 접근한 자료와 독립 검토가 별도로 필요하다. 로컬 검사 결과이며 이 시험브랜치 GitHub CI는 실행되지 않았다. 의미검색·최신순위·수천 개 무인수집 준비 완료를 뜻하지 않는다.
