# GG·불금의 제한된 용법 검증

GG는 본인이 참가한 게임에서 자신의 패배를 인정하는 용법만, 불금은 금요일 저녁 여가의 기대가 명시된 용법만 다룬다. GG의 일반 경기 후 인사나 타인 퇴장 요구, 불금의 모든 사용자 심리는 이번 주석 범위가 아니다.

## 근거와 경계
GG는 게임메카의 경기 보도와 인벤의 국내 채팅 관행 설명을 참고했다. 원게임 영상·채팅은 직접 읽지 않았으며 참가자 개인 신상은 복제하지 않았다. 자료는 표현의 사용을 뒷받침하지만 새 입력의 공식 경기 결과·기술적 종료·상대 수락을 확인하지 않는다.
불금은 정책브리핑의 공공 광고 활용 보도와 연합뉴스의 의미 설명을 참고했다. 원광고 영상·카드 이미지 세부는 직접 읽지 않았다. 금요일 여가는 음주·외출·모든 사람의 휴무를 필수로 뜻하지 않는다.

GG의 중심 대상은 패배를 인정하는 자기, 불금의 중심 대상은 여가 계획·상황이다. 전자는 정서 미판정, 후자의 기대는 명시된 용례가 전달하는 정서이며 실제 심리를 인증하지 않는다. 게임패배+자기 또는 금요일여가+상황이라는 좁은 필터 조건도 사실·날짜를 자동 검증하는 장치는 아니다.

## 실제 Python 개발 검증
a1c6cc6cf68b6ba2c0b4ca640f6bacf9af93a13a, GitHub Actions 44024876414에서 실제 Python 검색과 355 tests가 성공했다. 저장된 실제 AI 계획을 실행했으며 CI 중 새 모델 호출은 없다. 표제·예문을 뺀 공개 context 양성 2건과 공개 부적합 조건 4건, 기존 공개 질문 4건으로 구성한 개발평가다. 독립적인 자연어 정확도·인간 심사가 아니다.

- 자기 게임 패배 인정 → GG 1개.
- 명시적인 금요일 여가 기대 → 불금 1개.
- 다음 대회에 다시 나가겠다는 자기 다짐 → 중꺾마 자기 용법 1개. 게임 포기로 바꾸지 않았다.
- 이사하는 친구에게 좋은 앞날을 비는 인사 → 꽃길·행쇼 2개. GG 종료 인사를 끼워 넣지 않았다.
- 타인 퇴장 강요, 공식 종료·수락 보증, 잘못된 날짜·감정 단정, 야근 상대 놀기 압박, 쉬겠다는 친구 압박 → 보류.
- 이모지 입력 → 보충 질문.
- 기존 공개 A/E 계획의 후보 목록 변화 → 0.

네 양성·기존 대조 검색 모두 recommend 경로였다. 원본 주석의 draft 상태는 실제 검토 완료 전 유지하고 provisional copy에서만 테스트했다. 최종 답안과 개별 편집 검토, 승격·최종 check-only CI는 이후 단계이며 공개 trace·원 gold는 덮어쓰지 않는다.

## 개별 검토 결정과 남는 한계
최종 10개 답안의 방향·사실·조건을 별도 AI가 검토해 차단 오류를 찾지 못했고 두 용법만 좁게 reviewed로 이동한다. E06 원시 후보의 꽃길은 입력에 없는 새 활동을 보충해서 권할 수 없으며 최종 답안은 행쇼를 택했다. 후보 포함·상위 순위가 곧 최종 적합성이라는 뜻이 아니다. 중앙 승인 명세에는 검토된 두 ID/usage만 명시 추가했고 approved_revision은 이 검토의 답안·근거 리비전을 가리킨다. 최종 생성·check-only CI는 이후 정확 커밋에서 확인한다.
