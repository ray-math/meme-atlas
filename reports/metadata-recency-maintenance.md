# 메타데이터와 최근 목록 유지관리

- 표제어·태그·별칭은 각 Markdown 본문만 기준으로 삼습니다. 배치 이력의 과거 별칭은 검색 결과를 복원하지 않습니다.
- 병합된 옛 표제어는 배치 이력의 `superseded_by`를 통해 검색 문맥에만 남고 동의어로 취급되지 않습니다.
- `data/observations.json`은 검토된 관측 기록 원장입니다. 같은 밈을 다른 날짜에 관측하면 새 기록을 추가할 수 있습니다. 날짜·분류는 조사 확인 뒤에만 기록합니다.
- `python scripts/latest_collection.py --as-of 2026-11-16`으로 재현 가능한 최근 1년 목록을 생성합니다. `--as-of`를 생략하면 실행일을 씁니다. 윤년 2월 29일의 전년 경계는 2월 28일입니다.
- 최근 목록은 날짜 내 최신 관측을 밈당 한 개 선택하며 최대 200개입니다. 기간 밖 관측은 원장과 본문에 그대로 남습니다.
- 정기 편집 실행 시 본문 수정 후 `python scripts/build_index.py`, `python scripts/latest_collection.py`, 구조 검사와 전체 테스트를 수행합니다. 날짜를 바꾸는 것은 새 유행을 발견하거나 사실 확인을 했다는 뜻이 아닙니다.
