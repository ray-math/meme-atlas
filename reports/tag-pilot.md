## 분류 판단
- 원문에서 확인된 생성·확산 배경과 소재를 우선했다. 사진 속 음식 한 번이나 글 속 직업만으로 전체 밈의 태그를 단정하지 않았다.
- 방송·인터넷방송은 매체, 게임·음악·AI·음식 등은 분야/소재다. 이 둘은 복수 지정 가능하지만 당황·반전 같은 사용 상황은 넣지 않는다.
- 한국 수집 범위와 태그는 별개다. 기존 해외원형 검토대상에 게임 태그를 붙여도 한국원작으로 인증하는 것은 아니다.
- 확인된 별칭이 있는6개에만 aliases를 넣고 나머지10개는 생략했다. 같은 형식의 다른 예문을 전부 별칭으로 늘리지 않았다.

## 검증
- 기존16은 YAML을 제외한 본문 바이트가 이전과 동일하다. 월별 목차와 신규30 본문도 동일하다.
- 구조검사,29개 단위검사 통과. 태그에 당황 같은 상황을 넣는 경우, 중복, 잘못된 자료형을 거부하는 검사 포함.
- 검색 인덱스가 YAML 태그와 별칭을 읽는다. 별칭 없는 YAML 필드는 생략한다. 기존 신규30은 이전 별칭 인덱스를 유지한다.
- 세 배치 재실행 모두 변경없음/추가0. 원격 GitHub CI는 실행되지 않았으며 로컬 검사 결과다.
