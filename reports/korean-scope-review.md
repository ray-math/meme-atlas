# 기존 항목의 한국 범위 검토

신규 한국30 수집과 기존16 유지 여부는 별개다. 아래 항목은 신규 시험 목록에 포함하지 않으며 기존 본문·월별 링크를 삭제하거나 수정하지 않았다.

| 기존 ID | 점검 사유 | 현재 처리 |
| --- | --- | --- |
| take-the-l | 해외 원형과 한국 재현 맥락이 함께 있어 독립 한국식 변형인지 추가 확인 필요 | 기존 유지, 신규 한국30 제외 |
| criss-cross | 해외 원형과 국내 재현의 구분 필요 | 기존 유지, 신규 한국30 제외 |
| side-to-side | 해외 원형과 국내 재현의 구분 필요 | 기존 유지, 신규 한국30 제외 |
| my-emoji | 원 인터뷰의 제작·언어 맥락 추가 확인 필요 | 기존 유지, 신규 한국30 제외 |

나머지 기존12도 이번 신규30 시험에서 기원 사실을 새로 모두 검증한 것은 아니다. 따라서 전체 사전46개가 모두 한국 범위 인증을 받았다고 설명하지 않는다. 신규30 컬렉션만 이번 범위검토 대상이다.
