# 30항목 확장 시험 결과

## 1회차
- 국제 이미지 형식 10항목 조사·편집, 기존16 보존, 합계26.
- 이전 검사기가 관찰 월을 강제해 역사적 표본을 최근 유행으로 오인할 위험 발견. 월별 목차는 유지하고 별도 시험 수록 목록을 허용하도록 개선.
- 제목·별칭 정규화, 편집 검토와 근거 입력 gate, 재실행·사용자 편집 보호 추가.
- 관계가 약한 링크는 제거. 관련 링크는 의미/형식 비교이며 동일 기원이나 실제 공동 사용을 뜻하지 않음.
- 구조검사 통과, 18개 단위검사 통과, 같은 입력 재실행 추가0.
- 인덱스26항목 생성. 사실성은 웹 조사와 편집 검토로 확인한 범위이며 자동 보증하지 않음.
