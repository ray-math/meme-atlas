- 좌절 뒤 재도전: 중꺾마. 승리 보장이 아니라 의지를 말하므로 설명의 뜻에 맞는다.
- 불리한 조건이 풀이의 힌트가 됨: 오히려 좋아. 장난과 실제 긍정적 전환을 구별한다.
- 상식을 비껴가는 엉터리 풀이: 롤 세이프. 실제 권장 풀이인 것처럼 제목만 잘라 쓰면 오해할 수 있다.
- 두 방법 중 선택: 두 개의 버튼. 그림이 있어야 형식이 잘 전달되므로 제목 단독 활용에는 약하다.
- 예상 가능한 오답을 보고 놀람: 놀란 피카츄. 학생 개인을 조롱하지 않고 자기 실수를 표현하는 편이 적합하다.
- 위험한 풀이가 실패함: 관짝춤. 영상 전환 효과가 중심이고 실제 사고·죽음과 결합하면 부적절하므로 일반 제목용 추천에서는 신중해야 한다.

이는 편집자의 활용 적합성 점검이며 실제 시청자 반응 실험이나 자동 의미검색 평가가 아니다.

## 최종 한계와 다음 판단
- 세 배치 모두 실제 조사·편집·로컬 구조/회귀검사·같은 입력 재실행을 거쳤다. 외부 사이트 자료는 지시가 아니라 검토 자료로만 사용했다.
- 30개 전부를 독립된 최초 원전 두 개로 증명했다는 뜻은 아니다. 기원 불확실 표현은 최초 주장 자체를 하지 않았다. 재전재를 별도 독립 증거로 취급하지 않았다.
- 공개 본문의 출처 목록은 없으며 조사 입력/근거는 편집 작업공간에 별도로 보관한다. 향후 지속 운영은 접근제어된 근거 보관·리뷰 절차가 필요하다.
- 검색 인덱스는 표제어/별칭/짧은 정의/원문 경로만 제공한다. 의미검색·MCP·CLI 서비스·최신 인기도 판별은 구현하지 않았다.
- 자동 수집은 아직 사람 역할의 편집 판단을 포함하며, 3회의 배치 성공은 10년치/수천 항목 무인 운영 검증이 아니다.
- main과 주간 갱신은 변경하지 않았다. 시험브랜치만 업데이트. PR 제출은 별도 승인 요청이 필요해 현재 만들지 않았다. GitHub CI는 main/pull_request 트리거라 이 시험브랜치에서는 아직 실행되지 않았으며, 통과한 것은 로컬 검사다.
