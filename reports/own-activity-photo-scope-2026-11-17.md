# 자기 활동 기록 사진 용법의 제한된 검증

인증샷은 본인이 마쳤다고 설명한 활동의 기록 사진을 공유하는 한 용법만 주석한다. 사진은 매체이고 자기 경험이 중심 대상이다. 감정·자랑 목적을 자동 추정하지 않는다.

근거는 연합을 전재한 경향의 뜻풀이와 뉴스엔이 사진 공개에 붙인 유형명 보도다. 원게시물·SNS·이미지를 직접 관찰한 자료가 아니며 기사 속 개인 신상·법적 사건·신체평가는 복제하지 않았다. ‘인증’은 증거처럼 제시하려는 사용 목적이지 진위·완료·동의의 독립 검증 완료라는 뜻이 아니다.

8337b5a0966cbc751bb210983c60b579c9e80aa8, GitHub Actions 44027719512에서 실제 Python 검색과 378 tests가 성공했다. 저장된 AI 계획을 재실행했으며 CI에서 새 언어모델 호출은 없다. 표제·예문을 뺀 공개 context 1건, 공개 제외조건 4건, 기존 공개 질문 3건의 개발평가다.
- 자기 활동 기록 공유: 인증샷 1개를 recommend로 검색.
- 자기 도자기 작품 소개: 이 손을 봐 1개. 기록 사진과 창작품 자랑을 구별.
- 기둥 뒤에 공간 있어요의 뜻 질문: lookup 1개. 설명용 조회이며 사용 추천으로 바꾸지 않음.
- 남 사진으로 활동 확정·사진 세부 날조·민감 증빙 요구·무동의 촬영/공유: 보류.
- 이모지: 보충 질문.
- 기존 공개 A/E 후보 목록 변화: 0.

실제 사진을 도구로 관찰하거나 사진·활동·촬영 및 공유 동의를 검증한 평가가 아니다. 좁은 standard 분류와 사실오인 위험 표시는 편집 적합성 판단이며 자동 안전성 인증이 아니다. 사람 평가·미노출 자연어 정확도 결과로 일반화하지 않는다. 최종 AI 응답·개별 편집 검토·승격 후 check-only CI는 별도 단계다.

## 실제 실패와 개발 교정
v1 답안은 CI44028184288에서 381 tests 중 검토용 메타 검사1건이 실패했다. 원인은 P-record의 추천/미해결 조건 충돌, E18의 조회문장을 사용자 인용으로 넣은 오류2개다. 원본 전체를 answers-v1-unresolved.json에 보존하고 Git blob SHA와 같은 두 오류 재현을 테스트로 고정했다.

P-record는 response/reason에서 문구 초안 선택만 한다는 범위와 실제 공유 전 민감정보·촬영/공유 권한 확인을 명시했다. 현재 문구 판단의 unresolved가 없다는 기록은 미래 권한 확인 완료가 아니다. E18은 일반 정의 근거를 reason에 두고 factual_check에 실제 질문 원문만 넣었다. 다른6답안은 동일하다. checker는 완화하지 않았다.

119ce0f 교정본은 별도 AI 의미 재검토를 통과했고 8a9e4cab/CI44029085946 실제382 tests가 성공했다. 별도 코드 감사도 현재요청 미해결조건·exactlookup·caution 경계를 유지함을 확인했다. 이는 공개된 오류를 고친 개발회귀이지 새 블라인드 결과가 아니다. 이 좁은 용법만 reviewed로 이동하며 최종 색인·check-only CI는 해당 커밋에서 별도 확인한다.
