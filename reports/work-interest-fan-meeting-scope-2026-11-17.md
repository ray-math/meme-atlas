# 덕업일치·성덕의 제한된 용법 검증

덕업일치는 본인의 관심 분야가 현재 실제 업무와 이어진 상태, 성덕은 팬으로서 바라던 공식적인 자리의 만남·대화를 실제 경험한 자기 설명만 주석했다. 두 경우 모두 상태설명·자기·정서 미판정이며, 자랑 목적·행복·성공한 인생을 자동 부여하지 않는다.

## 근거와 편집 경계
덕업일치는 MBC의 실제 자기 발화를 포함한 공식 방송 텍스트와 이데일리 인터뷰 보도를 참고했다. 원음·영상은 재생하지 않았고 개인 건강 정보는 복제하지 않았다. 관심사와 일의 연결이 고소득·고용 안정·전문성·직업 만족을 보장하거나 저임금·과로를 정당화하지 않는다.
성덕은 경향의 용어 해설과 SBS의 SNS 자기 표현 보도를 참고했다. 원 SNS·영상은 직접 열람하지 않았다. 공식적인 자리라는 조건은 이번 좁은 context에 한정하며 모든 성덕의 사전 정의로 확대하지 않는다. 팬 교류가 상대의 팬 인지·상호 친밀감·지속 관계·추가 접근 동의라는 뜻은 아니다.

관심사직업연결과 팬교류성취는 실제 한 경험에서 함께 성립할 수 있다. 지금의 singleton 필수 필터가 넓은 OR를 차단하므로 필요한 경우 각각 조회한다. 두 뜻의 의미상 상호배타를 선언하거나 스키마가 모든 복합 맥락을 표현한다고 주장하지 않는다.

## 실제 Python 실행
361cceddac8a75f1b33e811dd809036b34b8a344, GitHub Actions 44025907769에서 실제 Python 검색과 366 tests가 성공했다. 저장된 실제 AI 계획을 실행했으며 CI 중 새 모델 호출은 없다. 표제·예문을 뺀 공개 context 양성 2건, 공개 부적합 조건 4건, 기존 공개 질문 4건을 사용한 개발평가이며 독립 인간·새 블라인드 정확도 측정이 아니다.
- 실제 관심사·직업 연결 → 덕업일치 1개.
- 실제 공식 팬 교류 경험 → 성덕 1개.
- 자기 도자기 작품 소개 → 이 손을 봐 1개. 작품을 만들었다는 사실로 직업·팬 교류를 추정하지 않았다.
- 가벼운 작별·행복 기원 → 꽃길·행쇼 2개. 원시 후보가 최종 적합성을 뜻하지 않으므로 문맥 선택이 필요하다.
- 취미·미래 희망을 실제 직업으로 바꾸기, 열정 착취, 사생활 침해, 추가 접근 동의 추정, 친절을 연애 확신으로 바꾸기 → 보류.
- 이모지 → 보충 질문.
- 기존 공개 A/E 후보 목록 변화 → 0.

양성·기존 대조 검색은 recommend 경로이며 원본 초안은 실제 개별 검토 전까지 노출하지 않는다. 최종 답안 검토와 승격·마지막 check-only CI는 별도 단계다. 원 trace·gold·메인 브랜치는 덮어쓰지 않는다.

## 개별 검토 결정
별도 AI가 최종 10개 답안의 사실·방향·조건을 검토해 차단 오류를 찾지 못했다. 두 용법만 위 범위로 reviewed에 옮기며, approved_revision은 검토한 답안·근거 리비전이다. E06 원시 후보의 꽃길을 입력에 없는 직업·활동으로 보충하지 않고 최종 행쇼를 택했다. 태그 일치·후보 순위는 최종 적합성이나 진실성·동의 인증이 아니다. 최종 생성 후 check-only 결과는 해당 정확 커밋 Actions에서 확인한다.
