# 추측 고지와 근거 비판: 공개 개발 점검

뇌피셜의 두 용법은 추측고지+상황, 주장근거부족+상황으로 분리했다. 기존 추측표현의 정황 기반 추론 정의는 넓히지 않았고, 근거 부족 지적을 허위 입증이나 인물 평가로 바꾸지 않았다. 모두 unknown·caution을 유지한다.

실제 Python 7a684c/CI44012914505에서 공개8입력을 실행했다. 새 두 용법, 킹리적 갓심 추론, 내로남불 기준 차이, 이왜진 확인 후 놀람이 각각 한 후보로 분리됐고 세 위험·불명확 사례는 검색하지 않았다. 기존 공개 계획의 후보 변화는0개다. trace44d0486, 실제 AI 답안1ed0601을 고정했다. 별도 AI는8답안에서 의미·사실·위험 경계 위반을 발견하지 못했다. 두 용법에 대해 개별 편집 검토했다.

기본 recommend는 caution을 제외한다. 정규 이름 lookup으로만 얻은 설명용 후보를 최종 recommend로 바꾸지 못한다. 필수 필터는 입력의 해석이지 근거 충분성이나 현실 진실을 검증하지 않는다.

공개 주석과 이름을 포함한 예문 및 이전 공개 질의를 재사용했다. 독립 블라인드 자연어 정확도·인간 합의·현실 안전성의 근거가 아니다. 같은 모델 계열의 반복 판단 편향을 배제하지 못한다. CI는 저장된 AI 계획의 실제 Python 재생이며 새 LLM 호출이 아니다. 출처의 정치적 주장이나 실제 민감 사건 내용은 사전·테스트에 복제하지 않았다.
