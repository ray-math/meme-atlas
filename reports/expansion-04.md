# 4회차 확장 시험

## 범위
기존46에서 한국 신규10을 더해56을 목표로 한다. 자료가 약한 후보는 수량을 맞추기 위해 통과시키지 않는다. main·주간 자동화·PR 제출은 변경하지 않는다.

## 도구 개선
- 기존16의 YAML 별칭이 배치 중복검사에서 누락되던 경로를 수정했다.
- 읽기 전용 키워드 검색에 제목·확인별칭 우선순위, 분야필터, 결과 제한, 알 수 없는 질의 빈결과를 추가했다.
- 신규30에도 검토된 YAML 분야태그와 확인별칭을 확장했다. 본문은 변경하지 않았고 메타데이터 개정 전 기존 해시를 검증한 뒤 배치 기록을 명시적으로 갱신했다.

## 수집 결과
한국 생성10개 추가: 뭣이 중헌디, 내가 왕이 될 상인가, 어이가 없네, 드루와, 지금까지 이런 맛은 없었다, 내로남불, 누칼협, 알빠노, 스불재, 손민수. 전체56개, 확장 시험 누적40개다.

## 내용 검토에서 수정한 점
- 일상문장과 영화의 밈 확산을 구분했다. 영화가 일반 문장 자체를 최초로 만들었다고 쓰지 않는다.
- 드루와의 대표 장면 인물과 배우를 구분했다.
- 알빠노 원영상 접근 실패를 확인해 PAKA·아지르·정확 연도 세부를 빼고 확인된 게임방송/커뮤니티 확산 및 언론 해설 범위로 축소했다.
- 손민수의 웹툰 원형과 드라마 확산, 사람/행동과 물건을 가리키는 파생어를 나눴다. 뜻풀이·파생어를 별칭으로 억지 등록하지 않았다.
- 한두 활용사례뿐인 학교·직장·게임·소비 태그를 일부 제외하고 중심 분야/소재만 남겼다. 웹툰·정치는 확인된 핵심 분야여서 태그 후보에 추가했다.

## 검증
- 구조검사 및38개 단위검사 통과. 동일4회차 입력 재실행은 변경없음/추가0.
- 기존46 본문은 YAML을 제외하고 모두 동일함을 확인했다. 기존 월별 목차도 그대로다.
- 확인된 별칭 럭키비키→원영적 사고, Criss Cross→크리스 크로스 우선검색, 게임/영화 분야필터, 미등록 질의 빈결과를 점검했다.
- 기존1~3회차 입력도 메타데이터 개정 뒤 재실행 추가0을 확인했다.
- GitHub CI가 아니라 로컬 검사 결과다. 내용 정확성은 별도 조사·교차검토이며 검사 숫자가 사실성을 인증하지 않는다.

## 합성자료 검색 부하 시험
실제 밈이 아닌 임시 인덱스로5회씩 측정한 중앙값:1,000개0.005259초,5,000개0.027554초,10,000개0.053144초. 이 환경의 선형 키워드 검색 비용일 뿐, 인터넷 검색속도·실제 최신밈 수집량·내용품질을 보증하지 않는다. 합성 항목은 사전에 추가하지 않았다.
