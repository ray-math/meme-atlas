# 첫 인사·작품 관심 요청의 제한된 검증

공개 자료에 근거한 만반잘부·많관부의 한 용법씩만 검토했다. 실제 심리·상대의 수용·홍보의 정당성을 판정하지 않는다.

## 근거와 분류
- 만반잘부: 중도일보와 브라보마이라이프의 뜻·첫 만남 사용 설명. 원대화 발화 직접 검증은 없다. 전달되는 반가움과 인사 기능을 주석했으며 입장자만 가능한 표현으로 고정하지 않았다.
- 많관부: 아시아경제의 뜻·작품 소개 설명과 일간스포츠의 제작발표회 발화 보도. 원생중계는 재생하지 않았다. 관심이 향하는 작품·활동을 중심 대상으로 두었으며 수신자와 구별했다.

새 상황은 첫만남과 작품활동소개다. 기존 만남시작은 재회를 포함하므로 변경하지 않았다. 관심요청의 정의만 보완했고 기존 안아줘요의 관심·위로 요청은 유지했다. 평면적 상황 라벨은 첫만남의 모든 다른 인사를 자동 회수하지 않으며 targets는 수신자·행위자·수혜자 전체를 별도 표현하는 스키마가 아니다.

## 실제 실행 범위
실행 커밋 f53b1a9ff242fe13fb23a4cfbb1b273a3b3dec4f, GitHub Actions 44022818432에서 Python 검색기와 335 tests가 성공했다. 저장된 AI 계획을 실제 Python에 적용했고, CI에서 새 언어모델을 호출한 것은 아니다. 새 2개를 메모리에서만 reviewed로 바꾸어 검사했다.

입력은 공개 주석의 context만 사용한 양성 2건, 공개 부적합 조건 2건, 기존 공개 재회 1건과 audit 질문 3건이다. 제목·예문을 새 양성 입력에 넣지 않았지만 주석에서 나온 문장이라 독립적인 미노출 자연어 정확도 증거는 아니다.
- 첫 인사: 만반잘부 1개.
- 작품 관심: 많관부 1개.
- 재회: 방가방가 1개. 첫만남 용법이 끼어들지 않았다.
- 자기 위로 요청: 안아줘요 1개. 작품 홍보로 바뀌지 않았다.
- 공식 소개·구매 압박: 추천 보류.
- 불명확한 공격 요청·이모지: 보충 질문.
- 기존 공개 audit/editorial의 후보 목록 변화: 0.

앞 세 양성은 검색기의 recommend 경로, 자기 위로는 lookup 후 문맥 검토 경로다. 후자를 기본 추천 정책의 허용으로 계산하지 않는다. 필터 일치만으로 격식·동의·진실성을 확인하지 않는다.

최종 AI 답변과 독립 편집 검토, 승격 및 마지막 check-only CI는 별도 단계다. 동일 모델 계열·공개 소표본의 개발회귀이며 인간 평가나 일반적 정확도·안전성 보증이 아니다. 원 baseline·gold·메인 브랜치는 변경하지 않는다.

## 좁은 범위 검토 결정
별도 AI 편집 검토는 8개 답안의 사실·방향·조건에서 차단 오류를 찾지 못했다. 실제 Python 문맥·원본 source SHA·검색 요구 조건을 유지한 2개 용법만 reviewed로 이동한다. 신규 무검증 일괄 승격은 하지 않는다. 최종 생성 후 check-only CI는 커밋별 Actions 결과에서 확인한다.
