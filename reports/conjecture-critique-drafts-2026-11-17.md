# 추측과 비판을 사실 판정에서 분리한 초안

2026-11-17. 기존 킹리적 갓심과 내로남불에 각각 1개 draft 용법을 준비한다. 새 표제 추가나 본문 수정은 아니며 검색·추천에 노출하지 않는다. 의도는 발화의 기능, 상황은 비교 조건, 사실 여부는 별도 검토 대상이다.

## 킹리적 갓심

[서울경제, 2021-04-15](https://news.nate.com/view/20210415n20945)는 강조형 의심의 의미와 거짓 매도·비아냥 위험을 설명한다. [코스모폴리탄, 2020-09-19](https://v.daum.net/v/20200919000027540)의 공개 기고는 자기 경험을 신조어로 재서술하며 의심 표현을 사용한다. 기고 속 사건 자체를 독립 취재로 확인한 자료라고 표현하지 않는다.

정황을 보고 가능성을 내놓는 추측표현은 결론을 보류하는 판단유보와 다르다. 표현의 강도가 실제 증거를 보장하지 않는다. 이번 초안은 실명 없는 가벼운 상황의 가능성에 한정하고 중대한 의혹·호감·동의 확정으로 확대하지 않는다.

## 내로남불

[경향, 2017-08-20](https://www.khan.co.kr/article/201708201117001/amp)와 [연합뉴스, 2025-07-04](https://www.yna.co.kr/view/AKR20250704044800001)는 이중 기준을 비판하는 실제 발화를 보도한다. 사용 사례의 확인은 비판 대상이 객관적으로 위선자라는 판단과 다르다. 기사에 인용된 사전 정의를 사전 원문 직접 열람으로 표시하지 않는다.

비판은 비꼼·조롱과 같은 기능이 아니다. 비교 가능한 두 행동에 기준이 달리 적용된다는 구체적인 조건을 확인하고, 이번 예문은 사람 자체의 가치가 아닌 기준 적용 방식을 대상으로 좁힌다. 새 정보·역할·사정의 차이나 단순 의견 차이를 무시한 낙인으로 쓰지 않는다. 자기성찰·직접 상대 호칭·반어 파생은 추가하지 않는다.

## 보류 상태

두 용례 모두 실제 감정은 unknown, 안전 등급은 caution인 편집 판단이다. 예문은 창작이며 기사 인용이 아니다. 출처와 의미 검토는 자연어 검색 성능·주장의 진실성 검증을 대신하지 않는다. 실제 Python 긍정·반례 검증 전에는 draft를 유지한다.
