# 30항목 확장 시험 계획

기존 16항목과 사용자 편집을 보존하고, 새 표본 10개씩 3회 수집·편집·검사를 수행한다. 최근 유행 순위나 2026년 특정 월의 신규 유행을 입증하는 시험은 아니다. 오래된 국제 이미지 밈, 국내 표현, 인터넷 리액션/영상 밈을 섞어 명칭·유래·관계·실제 활용의 다양성을 검증한다.

## 진행
1. 국제 이미지 형식 10항목: 원전·이미지 맥락과 표제어, 상호 관계.
2. 국내 표현 10항목: 별칭과 뜻 차이, 원조 주장 충돌, 제목/대사 활용.
3. 인터넷 리액션·영상 10항목: 음악·동작 의존성, 파생 관계와 오용 위험.

각 회차는 조사 입력 → 편집 검토 → 중복 검사 → 별도 브랜치에 원자적 Git 커밋 → 구조/회귀 검사 → 같은 입력 재실행(0개 추가)을 확인한다. 근거 URL은 편집용 조사 입력에 보존하되 독자용 항목에 노출하지 않는다. 조사 입력은 이 공개 저장소에 커밋하지 않는다.

## 통과 기준
- 근거를 실제 열람하고 강한 기원 주장을 교차검토. 확인 안 된 최초 시점/원작자/사용례는 보류하거나 표현 축소.
- 한 밈 한 파일, 별칭 정규화 충돌 0, 기존 사용자 수정 덮어쓰기 0.
- 인용은 짧은 실제 표현만. 상황 설명을 실제 대사처럼 꾸미지 않음.
- 내부 링크·역링크·전체 목차 검사 통과. 새 표본을 근거 없이 월별 유행 목록에 넣지 않음.
- 재실행 추가 0, 입력 변경·사용자 편집 탐지 시 중단.
- 회차별 처리 결과·실패·수정·검증 한계를 기록. 구조 성공은 사실성 또는 대량 무인 수집 준비 완료를 보증하지 않는다.

## 경계
전용 CLI/MCP/서버를 배포하지 않는다. 유료 서비스·API를 구매하지 않는다. 한 테스트 브랜치와 초안 PR만 사용해 주간 main 갱신과 분리한다. 30항목 시험 결과를 검토하기 전 수천 항목으로 확대하지 않는다.
