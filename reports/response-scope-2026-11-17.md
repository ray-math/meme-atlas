# 반응 불일치와 관대한 평가: 공개 개발 검증

이 보고는 AI 편집 주석과 공개 개발 입력을 평가한 기록이다. 인간 평가나 미노출 자연어 정확도, 현실의 관계·성과·안전성 인증이 아니다.

## 발견과 수정

너 T야?를 넓은 장난스러운항의, 까방권을 넓은 칭찬만으로 검색하면 기존 공개 계획 8개 기록에 부적합한 후보가 추가됐다. 영화식 장난 항의와 문자적 반응의 불일치는 다르고, 성취를 축하한다고 미래 실수에 관대하겠다는 뜻이 생기지는 않는다. 이는 8개의 최종 답안 오류라는 집계가 아니라 후보 변화다.

- 너 T야?: 반응기대불일치 상황을 단독 필수값으로 요구한다.
- 까방권: 관대한평가 의도를 단독 필수값으로 요구한다.
- 같은 축의 넓은 OR는 필수 단일값 조건을 만족하지 않는다.
- 정확한 이름 lookup 예외는 의미 설명에만 쓰인다. 공통 선택검사에서 exact_lookup_only 후보 또는 필수 조건 미충족 후보를 최종 recommend로 바꾸는 것을 거부한다.
- 두 용법은 unknown 정서와 caution을 유지한다. 기본 recommend에서는 제외되며 조건 필터는 실제 문맥·사실 확인을 대신하지 않는다.

## 실제 실행과 불변 기록

수정 전 baseline-retrieval.json은 실제 Python CI 44008161810의 결과를 보존한다. 수정 후 retrieval.json은 0a8f813, CI 44008682180 실행 결과이며 723aabf에 고정했다. 필수 조건 적용 시 기존 후보 변화는 0개, 조건을 끈 대조 실행은 원래 8개 변화를 재현한다. 원래 plans, answers, gold를 이 수정에 맞춰 덮어쓰지 않았다.

공통 선택 guard와 엄격한 정수 schema_version 보완은 a6e398d, CI 44009367803에서 258 tests를 통과했다. True나 1.0을 schema version 1로 인정하지 않는다.

8개 최종 답안은 별도 AI가 실제 trace를 읽고 작성해 f2a450a에 고정했다. 별도 AI 편집 검토에서 8개 모두 의미·사실·위험상 차단 문제를 발견하지 못했다. T-protest/S-leniency는 좁은 긍정 선택, A01/A14는 기존 적합 용법, A17/A18/A20은 보류, A23은 맥락 질문이다. 이 판단은 자동 점수나 인간 합의가 아니다.

## 범위와 한계

특히 긍정 2건에는 밈 이름과 주석의 사용 조건이 들어 있다. 따라서 자연스러운 미노출 요청에서 의도와 상황을 추출하는 일반 성능을 입증하지 않는다. CI는 저장된 AI 계획을 실제 Python 검색기로 재생하며 새 LLM을 호출하지 않는다. 최종 응답의 사실 점검은 입력 문구에 대한 근거 일치이지 현실의 사건 검증이 아니다.

정확 이름 조회의 의미 설명 가능성과 사용자에게 그 표현을 보내도 되는지는 별개다. 이 검토는 프로필의 좁은 용법을 편집 검토하는 것이며, 모든 맥락의 자동 추천을 승인하지 않는다. main 병합은 하지 않는다.
