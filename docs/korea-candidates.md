# 대한민국 목록 후보대장

[data/korea-candidates.json](../data/korea-candidates.json)은 **편집용 조사 대기열**이다. 공개 사전 본문, 수록 권장 목록, 최신 유행 목록이 아니다.

## 자료와 범위
- 요청된 나무위키 원본은 직접 접근하지 못했다. JSON에 명시한 나무모에 미러의 실제 본문 전체를 읽었다. 표제와 목록 위치만 저장하고 설명·각주·이미지·영상은 복제하지 않았다.
- 2026-11-16 스냅샷: 숫자/외국어/ㄱ~ㅎ 16구간, 최상위 1,070줄과 하위 21줄, 합계 1,091줄. 이는 독립 밈 1,091개라는 뜻이 아니다.
- 최신 수집 지시의 범위는 **한국에서 실제 밈으로 쓰인 유용한 개별 표현·동작**이다. 해외 기원도 독립 검증 후 포함할 수 있다. 현재 CONTRIBUTING의 수집 범위와 같은 기준이며 국내 실제 사용과 뜻을 별도로 검증한다.
- 작품·인물·게임 전체를 하나의 밈으로 발행하지 않는다. 실제 독립된 문구/동작으로 나누거나 보류한다.
- 원본 목록의 문장/사실 주장을 검증된 설명처럼 가져오지 않는다. 원본의 수정 시각은 관찰일이 아니다.

## 상태와 변경
- `unreviewed`: 미검토. 독립 자료와 실제 사용, 범위, 중복을 조사한다. evidence가 있어도 발행 승인은 아니다.
- `held`: 보류. 이유를 notes에 남긴다. 초기 4개는 성적 충격물/극단주의 관련 소재 가능성 때문에 미디어를 재현하지 않고 중립 설명 가능성부터 검토한다. 이후 국내 실제 사용의 독립 근거가 부족한 항목도 이유를 적어 보류한다. 보류되지 않은 나머지가 안전하거나 검증됐다는 뜻은 아니다.
- `duplicate`: 목록 내부 중복. duplicate_of로 대표 후보를 가리킨다. 별도 의미가 확인되면 이유를 남기고 분리한다.
- `included`: 기준 사전에 이미 수록. dictionary_paths에 실제 경로를 둔다. 기존 내용의 사실성·수록 범위를 재인증하는 상태는 아니다.

상태 변경은 기존 객체의 id를 유지하고 notes에 이유와 날짜를 추가한다. 보류를 미검토로 되돌릴 때도 사유를 지우지 않는다. 새 목록을 읽었다는 이유로 기존 상태·근거·수동 판단을 초기화하지 않는다.

## 정체성과 중복
id는 이번 스냅샷의 줄 위치로 처음 부여한 영구 식별자다. 다음 스냅샷 줄번호로 재할당하지 않는다. source_line은 이 스냅샷에서만 의미 있다. parent_id는 원본의 목록 계층이지 의미상 파생 관계가 아니다.

제목은 목록 행의 설명을 제거한 작업용 표제이며 확정 표제어가 아니다. 한 줄의 여러 표현, 괄호, 포괄 이름은 사람 검토가 필요하다. 줄 하나를 분리할 때는 기존 후보를 보존하고 notes에 새 후보 id를 기록한다. 새 객체에는 고유 id와 해당 source_line을 둔다.

초기 수록 대조는 GitHub main 검색색인 178개 기준 제목·별칭의 공백/일부 구두점 정규화 일치다. **의미 중복 전체를 판정하지 않는다.** 초기 상태는 수록 58, 중복 5, 보류 4, 미검토 1,024이며 이후 작업으로 바뀐다. 미검토 수를 신규 발행 가능 수로 보고하지 않는다.

## 기존 조사와 연결
- 기존 수록 148개와 [PR #6](https://github.com/ray-math/meme-atlas/pull/6)의 신규 30개는 기준 검색색인에 포함된다. 일치한 후보는 dictionary_paths로 연결했다. 표기 차이로 놓친 항목은 수동 연결한다.
- 우왕ㅋ굳ㅋ, 킹왕짱, 킹리적 갓심, 트로피카나 스파클링에는 실제 읽은 독립 기사와 발행일을 evidence에 연결했다. 이 네 항목은 독립 본문 검토 후 PR #11로 수록됐다.
- 흠좀무·안습·엄친아·고고씽은 보조 조사 후보지만 이 목록 내 위치를 확인하지 못했으므로 목록에 있었던 것처럼 추가하지 않았다.
- [PR #7](https://github.com/ray-math/meme-atlas/pull/7)의 ○○냥이는 main에 반영돼 당시 사전은 179개였다. 이 스냅샷 목록에서 확인한 후보가 아니므로 목록에서 발견한 것처럼 추가하지 않는다. 다른 진행 중 PR은 실제 main에 반영되기 전 수록으로 바꾸지 않는다.

- [PR #11](https://github.com/ray-math/meme-atlas/pull/11)에서 독립 검토한 13개가 main에 반영돼 당시 비교 색인은 192개였다.

## 수록 절차
1. 최신 main, 기존 본문·aliases, 대장 상태를 읽는다.
2. 원본 사용 사례와 독립 해설을 읽고 제목·뜻·사용·국내 맥락을 확인한다. 검색 요약만으로 확정하지 않는다.
3. 증거는 편집 대장에 URL, 실제 발행일, 접근 범위(body_read / snippet_only / unavailable), 검토일을 기록한다. 출처 목록을 사전 본문에 늘어놓지 않는다.
4. 옛 기사의 날짜를 최근 관측으로 쓰지 않는다. 최초 유래를 확인하지 못하면 단정하지 않는다.
5. 검증한 개별 밈만 독자적으로 작성하고 기존 저장소 검사와 CI를 통과시킨다.
6. main 반영을 확인한 다음 included와 dictionary_paths를 갱신한다. PR만 열린 상태는 unreviewed를 유지하고 notes에 PR 링크를 적는다.
7. 중복/보류/미검토 개수와 실제 추가 수를 분리해 보고한다. 전체 원본 목록을 검증 완료했다고 주장하지 않는다.

## 유지 시 검사
JSON 파싱, id 유일성, 허용 상태, 부모/중복 대상 존재, included의 실제 파일 경로를 확인한다. 기존 검사기는 이 대장의 의미나 출처를 검증하지 않는다. 독립 자료 확보가 막히면 보류로 기록하고 다른 후보를 진행한다.
