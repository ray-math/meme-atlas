# 날짜 구분 정렬 시제품 안내

[날짜 구분 정렬 시제품](../collections/date-prototype.md)은 기존 23개만 대상으로 합니다. 관측일이나 최근 유행 정렬의 대체물이 아닙니다.

- 원작 관련 판본 공개일(source_edition_publication): 발행 매체·판본을 note에 기재합니다. 최초 연재일이라고 추정하지 않습니다.
- 밈 발생 시점(meme_emergence): 밈으로 사용되기 시작한 시점의 근거가 있어야 합니다. 이번 예시는 모두 미상입니다.
- 검토 자료 내 한국 사용 확인일(korean_attestation): 검토한 자료에서 확인한 가장 이른 사례입니다. 한국 전체 최초 사용일이라고 주장하지 않습니다.
- value는 YYYY, YYYY-MM, YYYY-MM-DD 또는 null입니다. precision은 year/month/day/unknown으로 분리합니다. 알려진 날짜에는 HTTPS 근거와 설명이 필요합니다.
- 오름·내림 모두 미상은 마지막입니다. 부분 날짜는 기간 시작을 계산 키로만 쓰고 표시 날짜를 보간하지 않습니다. 겹치는 기간의 실제 선후는 미확정이며 동일 키는 ID순입니다.
- 날짜의 정밀도는 사실의 신뢰도 등급이 아닙니다.

## 실행

```sh
python scripts/historical_dates.py --kind source_edition_publication
python scripts/historical_dates.py --kind meme_emergence
python scripts/historical_dates.py --kind korean_attestation --descending
python -m unittest discover -s tests -p test_historical_dates.py -v
```

출력만 하는 CLI입니다. 관측 원장, 최근 목록, 검색 순서, 본문 파일은 바꾸지 않습니다. 정적 예시는 첫 명령의 출력이며 회귀검사에서 일치 여부를 검사합니다.

## 검증 예시

- 허나 거절한다: 원작 판본 공개 미상 / 밈 발생 미상 / 한국 사용 확인 2021-10-14(일 정밀도). 국내 기사에 실린 사용이며 최초 한국 용례로 확정하지 않습니다.
- 언제부터 ~라고 착각한 거지?: 원작 관련 판본 2010-06-04(일 정밀도) / 밈 발생 미상 / 한국 사용 날짜 미상. 첫 날짜는 일본 블리치 45권 종이책 발매일이지 대사 최초 연재일이 아닙니다.

- 니코니코니: 원작 공개·밈 발생 미상 / 한국 사용 확인 2016-06-13(기사 발행일). 보도된 방송일 6월 11일과 구별합니다.
- 느리구나, ○○하는 것조차: 원작 공개·밈 발생 미상 / 한국 사용 확인 2026-09-21(국내 변형 소개 글). 원영상 게시일·시청 여부와 구별합니다.
- 이것은 내가 ○○가 되기까지의 이야기다: 원작 공개·밈 발생 미상 / 한국 사용 확인 2026-10-13(직접 제목 적용). 작품 전체 방영기간을 대사 최초 공개일로 쓰지 않습니다.

- 하이닉스 조끼: 국내 상황극 사용 보도 2026-04-28. 프로그램 공개 4월25일과 구별합니다.
- 생사과가 제일 맛있었어요: 심사평 인용 기사 전송 2025-12-25. 수정일과 첫 패러디 제작일이 아닙니다.
- 말 있죠?: 드라마 문체 패러디 보도 2026-03-25. 원영상 최초 공개나 작가의 실제 발언 날짜로 보지 않습니다.

앞 묶음의 하이닉스 조끼·생사과가 제일 맛있었어요·말 있죠?는 원작 관련 최초 공개일과 밈 발생일을 미상으로 유지합니다.

- 카페베네 엔딩: 관련 최종회 방송 2010-03-19 / 국내 명칭·편집 형식 논의 2015-10-07. 최종회 날짜를 밈 제작일로 쓰지 않습니다.
- 사딸라: 협상 장면이 있는 84회 방송 2003-05-13 / 광고 차용 보도 2019-01-03. 광고 집행 기간과 최초 밈 발생을 구별합니다.
- 멋지다 연진아: 넷플릭스가 안내한 작품 공개 2022-12-30 / 화보 기사 제목 차용 2023-01-20. 안내문 작성일은 2022-12-15입니다.

이번 추가 3개의 밈 발생일도 미상입니다.

연·월 정밀도도 근거가 제공하는 범위에서만 표시합니다. 날짜가 부분적으로 확인되더라도 월초·연초의 실제 날짜로 바꾸지 않습니다. 조사 범위를 전 사전으로 확장하거나 기존 최신 목록을 이 기준으로 대체하지 않았습니다.

## 후속 일상 표현 예시

- 도비는 자유예요: 퇴사 예정 직장인의 프로필 사용 보도 2021-06-07. 영화 개봉일이나 밈 발생일로 보지 않습니다.
- 올 때 메로나: 표현을 비튼 캐릭터 이름 사용 보도 2020-06-13. 이번에 원문을 읽지 못한 2011년 웹툰 주장은 날짜 근거에 넣지 않았습니다. 최초 사용일은 미확정입니다.
- 궁금하면 오백원: 원방송 사용 2012-09-02와 이를 보도한 기사 2012-09-03을 구분합니다. 대사가 밈으로 퍼진 최초 시점은 미상입니다.

## 후속 영화 대사 예시

- 친구 아이가: 《친구》 한국 극장 개봉 2001-03-31 / 비평 기사 대사 인용 2005-11-17.
- 아버지 뭐하시노: 같은 영화 개봉 2001-03-31 / 《친구2》 제작보고회 재연 2013-10-17.
- 어이가 없네: 《베테랑》 한국 극장 개봉 2015-08-05 / 어원 해설 기사 인용 2015-09-29. 수정일 9월30일과 구별합니다.

세 항목의 밈 발생일은 미상이며, 극장 개봉일은 예고편 최초 노출일이 아닙니다. 기사 인용·재연 날짜 역시 한국 전체 최초 사용일이 아닙니다.

## 광고·게임 후속 예시

- 여러분 모두 부자되세요: 광고 방영 2001-12(월 정밀도), 당시 덕담 유행 기사 2002-01-24. 첫 송출일은 특정하지 않습니다.
- 잘자 내 꿈 꿔: 광고 회고에서 제시한 1999년(연 정밀도), 변형 유머 보도 2000-04-03. 후대 회고 연도와 당시 기록일을 구별합니다.
- 다메다메: 원곡 최초 판본 공개 미상, 국내 생성기 소개 글 2020-09-22. 링크된 영상 자체의 게시일은 확인하지 않았습니다.

이 세 항목의 밈 발생일도 미상입니다. 월·연 정밀도 표시는 자료가 제공하는 범위이며 실제 최초 날짜 확정이나 정밀도에 따른 신뢰도 순위가 아닙니다.

## 영화 대사의 후속 차용

- 모히또 가서 몰디브 한잔: 원개봉판 공개2015-11-19 / 배우 인터뷰 인용2015-12-23. 확장판 개봉12월31일과 구별합니다.
- 밥은 먹고 다니냐: 영화 공개2003-04-25 / 국내 사용 확인일 미상. 상호 차용 기사의 입력·수정일이 역순이라 특정하지 않았고, 별도 광고 보도2018-11-29와도 구별합니다.
- 지금까지 이런 맛은 없었다: 영화 공개2019-01-23 / 예고편 대사 인용 기사2019-01-14. 대사는 극장 개봉 전에 공개됐으므로 개봉일을 최초 노출일로 삼지 않습니다.

세 항목 모두 밈 발생일은 미상입니다.
