# 용어와 필터의 역할

이 분류는 한국 밈에 대해 검증된 보편 심리학 표준이 아니라, 소규모 사전에서 AI가 후보를 찾는 데 쓰는 편집용 어휘다. 검색 필터는 확신 있는 조건에만 사용하고, 애매한 조건은 최종 문맥 판단으로 남긴다.

## 여섯 축

- **전달 정서(emotions)**: 해당 용례의 말투가 드러내는 정서적 색채다. 장면 속 사람이 느낄 감정이나 사용자의 실제 내면이 아니다. 웃긴 장면에 엄숙하게 대응할 수도 있으므로 장면의 재미를 필수 필터로 옮기지 않는다.
- **대화 기능(intents)**: 말로 무엇을 하는가. 동의·격려·자조·제지 등을 구별한다. 숨은 의도를 심리적으로 확정하는 분류가 아니다.
- **사건 조건(situations)**: 이 용례에 맞는 구체적인 사건. 단순 소재나 등장인물의 속성과 다르다. 타인의 결과에 감탄하는 것과 내 결과를 자랑하는 것은 다르다.
- **중심 대상(targets)**: 표현의 평가·도움·제지가 중심적으로 향하는 대상. 수신자를 무조건 상대 태그로 변환하지 않는다.
- **대화환경(registers)**: 기존 이름을 유지하는 호환 필드다. 채널과 말투를 함께 기록하는 비배타적 태그이며 엄밀한 사회언어학적 register 분류가 아니다. 온라인댓글은 친밀관계를 보장하지 않는다.
- **검토 위험(risk_flags)**: 오인·관계·피해에 관한 확인 항목. 표제 전체의 유해성 판정이나 사람에 대한 낙인이 아니다.

## 혼동하기 쉬운 구별

응원은 잘되기를 바라는 지지, 격려는 행동할 힘을 북돋는 기능이다. 서로 겹칠 수 있으므로 자연어 요청이 넓다면 두 기능을 OR로 탐색하고 상황을 보고 고른다. 동일어로 강제 병합하지 않는다.

자조는 자신을 웃어넘기는 방식이지 모든 자기모순·실수를 하나의 용법으로 묶는 허가가 아니다. 반복 표현, 과도한 설명, 기대와 현실 차이 등 구체적인 적용 조건을 확인한다.

감탄과 자랑은 발화의 방향이 다르다. 위로 요청과 위로 제공도 반대 방향이다. 단어의 긍정성만으로 같은 결과에 연결하지 않는다.

중립기어는 판단을 유보하는 기능이며 감정이 없다는 판정이 아니다. emotion_status의 unknown은 판단하지 못함, not_applicable은 해당 정서 축을 적용하지 않는다는 명시 검토, annotated는 라벨을 부여했다는 뜻이다. 빈 배열을 중립으로 자동 채우지 않는다.

## 검색기가 하지 않는 일

정의에 있는 관련어를 무조건 동의어로 확장하지 않는다. 어휘표의 aliases만 정규화한다. 서로 다른 축과 용법을 섞지 않는다. 필터가 너무 강해 무답이 나왔다고 원래 요청의 금지 조건을 버리지 않는다.

`python scripts/search_usage.py --describe-facets`로 버전이 고정된 축 설명과 주요 개념 정의를 조회할 수 있다. 어떤 용어가 여전히 애매하다면 exact 태그를 추측해 넣기보다 조회 범위를 좁히지 않고 문맥을 읽는 편이 낫다.
