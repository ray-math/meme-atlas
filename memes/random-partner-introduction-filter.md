# 랜덤 애인 소개 챌린지

## 뜻풀이

무작위로 표시되는 나이·직업 같은 설정을 읽으며 가상의 애인을 소개하는 숏폼 챌린지다. 예상 밖의 설정에 반응하면서 소개를 이어가는 형식이다.

## 유래와 확산

2026년 11월 13일 트렌드어워드는 ‘in love with’ 필터를 사용하는 형식과 여러 국내 계정의 사례를 소개했다. 같은 글은 자녀의 애인을 소개하거나 스포츠 선수 영입을 연출하는 변형도 설명한다. 기사 1건에서 복수 사례를 소개한 것이며 개별 SNS 게시물과 영상은 직접 확인하지 않았다. 글 앞부분의 가상 용례는 실제 이용자 발언으로 세지 않으며 최초 발생일이나 전체 참여 규모도 확정하지 않는다.

## 사용 시 주의

필터가 만든 가상 설정을 실제 사람의 정보처럼 퍼뜨리지 않는다. 신체 조건·국적·나이를 기준으로 사람을 비하하는 예문이나 미성년자를 성적 대상으로 묘사하는 변형은 사용하지 않는다.
