# 나무위키 꺼라

**온라인 표현 · 패러디**

## 뜻풀이
위키에서 본 설명만으로 아는 척하거나 근거를 단정하는 태도를 놀리는 말. 정보의 출처를 다시 확인하라는 뜻을 비꼬아 전달한다.

## 유래와 확산
2019년 한국어 Reddit 대화에서 위키로 답을 찾는다는 질문에 이 표현을 농담으로 쓰는 댓글이 확인된다. 2025년 채널예스 칼럼은 출처를 검증하지 않은 위키 의존을 지적하는 밈으로 해설했다. 댓글은 실제 사용 사례이지 최초 발생의 증거는 아니다.

## 사용 시 주의
이 말만으로 특정 정보가 틀렸다고 증명되지는 않는다. 작성자나 이용자 집단을 공격하기보다 원출처를 확인하는 편이 낫다.
