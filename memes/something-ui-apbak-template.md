# ○○의 압박

## 뜻풀이

부담스럽거나 감당하기 어려운 대상을 앞에 넣어 ‘○○의 압박’이라고 과장하는 옛 온라인 표현이다. 긴 글의 분량을 알리는 스크롤 압박은 이 결합 형식의 한 용법이다.

## 유래와 확산

중앙일보의 인터넷 신조어 소개는 결합 예시와 번역 오류에서 비롯됐다는 설명을 실었다. 장경현의 2011년 논문 ‘신조어 연어의 형성 원리’도 명사를 바꾸는 결합 형식과 영어·스크롤 관련 응용을 다룬다.

기사와 연구의 해설 두 군을 확인했다. 자료 속 예시를 서로 다른 원게시물로 세지 않는다. 최초 사진과 게시 시점은 직접 확인하지 않았으며 중앙일보 페이지의 정확한 발행일도 현재 추출문에서 확인되지 않아 적지 않는다. 논문은 텍스트를 읽었고 이미지·사진은 열람하지 않았다.

## 사용 시 주의

일반적인 강제력이나 실제 압박 사건을 모두 인터넷 농담으로 해석하지 않는다. 타인이 겪는 어려움을 가볍게 만드는 용법은 피한다.
