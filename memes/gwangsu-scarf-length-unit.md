# 1광수 목도리 단위

## 뜻풀이

목도리 길이를 이야기할 때 190센티미터를 ‘1광수’로 부르는 장난스러운 단위 표현이다. 뜨개질한 길이를 소수로 바꿔 말하거나 긴 목도리를 지칭하는 데 쓰이며 실제 인체 치수를 정확히 정의하는 단위는 아니다.

## 유래와 확산

인크로스의 2025년 11월 19일 글은 목도리 영상의 댓글에서 이어진 단위 놀이를 설명한다. 더쿠의 2025년 11월 18일 질문 글은 목표 길이를 이 표현으로 적었고, 쎄비 커뮤니티의 2026년 1월 4일 완성 후기도 같은 표현을 사용했다. 두 플랫폼의 직접 사용 텍스트와 해설을 확인했으며 사진·원영상과 최초 댓글은 직접 확인하지 않았다.

## 사용 시 주의

인물의 실제 키나 외모를 단정하는 근거로 삼지 않는다. 제품 제작에 필요한 정확한 길이는 실제 치수로 확인해야 하며 상품 추천이나 제작법 검증을 뜻하지 않는다.
