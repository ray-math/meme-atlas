# 알 수 없는 유튜브 알고리즘

**온라인 표현 · 패러디**

## 뜻풀이

예상하지 못한 영상을 추천받아 보게 된 일을 알고리즘이 자신을 데려온 것처럼 말하는 댓글형 농담이다. 뜻밖의 발견에 대한 놀라움이나 만족을 담는다.

## 유래와 확산

2021년 뉴스1은 추천 영상에 도착한 사정을 이렇게 말하는 댓글을 밈으로 소개했다. 2023년 유튜브 분석 서비스의 글에도 같은 문형이 인용됐다. 추천 피드에 등장하겠다고 춤추는 영상 챌린지와는 다른 형식이다.

## 사용 시 주의

추천 시스템의 실제 작동 원리를 설명하는 문장이 아니다. 특정 이용자의 시청 기록이나 취향을 안다고 단정하는 데 쓰지 않는다.
