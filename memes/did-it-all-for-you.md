# 다 해줬잖아

## 뜻풀이
자신이 해 준 일이나 이미 충족한 조건을 나열한 뒤, 생색이나 불만을 과장하며 덧붙이는 말틀이다. 여러 행동을 반복해서 열거하고 마지막에 한꺼번에 묶어 강조한다. 같은 문장이 평범한 대화에도 쓰이므로, 모든 사용을 특정 노래의 패러디로 단정하지 않는다.

## 유래와 확산
[2024년 10월 26일 연합뉴스 보도](https://www.yna.co.kr/amp/view/AKR20241025120300017)는 메이플스토리 운영을 풍자한 AI 합성 노래와 후속 합성물 확산을 설명한다. 여기서는 실존 인물의 합성 영상이나 노래 전체가 아니라, 다른 상황에 옮겨 쓰는 문자 표현만 다룬다.

[트렌드어워드의 활용 글](https://v.daum.net/v/2xKpQff5W2)은 업무와 날씨에 표현을 직접 적용하고, 여러 행동을 나열해 생색이나 불만을 나타내는 텍스트 패러디 형식을 설명한다. 열람한 본문에는 발행일이 표시되지 않아 정확한 날짜는 확정하지 않는다.

[2026년 6월 9일 SBS 기사](https://v.daum.net/v/XDTDJ00H7f)는 조건을 갖췄는데도 원하는 결과를 얻지 못한 상황을 소개하는 제목에 같은 문구를 사용했다. 최근 제목 사용은 확인되지만, 매체가 노래를 의도적으로 차용했다고 밝힌 자료는 아니다.

## 주의
합성 노래를 실제 인물의 발언으로 인용하지 않는다. 연합뉴스는 해당 영상이 초상권 침해 문제의 사례로 다뤄졌다고 보도했다. 불만을 표현하는 말틀과 특정 개인을 조롱하는 합성물 재배포를 구분한다.
