# 환승연애3 예고 대사 장면 바꾸기

## 뜻풀이

《환승연애3》 예고편의 사과를 요구하는 대사에 다른 드라마 장면을 붙여 관계의 감정을 새로 구성하는 영상 편집 놀이이다. 대사를 다른 작품의 인물 관계에 겹쳐 놓는 형식이다.

## 유래와 확산

2023년 12월 19일 코스모폴리탄은 예고편 대사와 드라마 장면을 결합한 밈을 설명하고 티빙이 여러 작품으로 해당 편집에 참여했다고 소개했다. 한 매체가 전한 구체 제작 사례를 확인했으며 예고편이나 편집 영상은 보지 않았다. 최초 편집자와 확산 규모를 확정하지 않는다.

## 사용 시 주의

편집 장면을 원작의 실제 대화나 출연자의 사생활로 오해하지 않는다. 대사 전문과 영상·음악을 복사하지 않으며 실제 연인에게 특정 행동을 강요하는 말로 쓰지 않는다.
