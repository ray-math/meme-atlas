# 고고씽

## 뜻풀이

가거나 시작하자는 뜻을 신나게 표현하는 온라인 말이다.

## 유래와 확산

2007년 12월 매일신문과 미주중앙일보의 통신언어 소개에서 뜻을 확인할 수 있다. 두 기사는 같은 시기 설문을 다루므로 독립된 사용 사건 두 건으로 세지 않는다. 2013년 8월 22일 매일신문 여행 글의 부제에서는 목적지를 제시하며 이 말을 직접 적용했다.

## 사용 시 주의

확인된 것은 역사적 뜻 해설과 여행 문안의 사용이다. 게임에서 시작됐다는 추정은 기원으로 채택하지 않았고 최초 발생과 전체 유행 규모, 최근 1년 사용은 미확정이다. 같은 이름의 계정과는 구별하며 사진·영상은 직접 보지 않았다.
