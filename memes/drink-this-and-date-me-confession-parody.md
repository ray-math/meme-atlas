# 이거 마시면 나랑 사귀는 거다

## 뜻풀이

음료를 마시는 행동에 연애의 시작이라는 조건을 붙여 영화 속 고백 장면을 재현하는 말틀이다. 대사와 상대의 반문을 주고받는 짧은 상황극으로도 옮긴다.

## 유래와 확산

2018년 6월 19일 iMBC는 드라마 어바웃타임의 촬영 장면을 영화 내 머릿속의 지우개의 고백 장면 재현으로 설명했다. 2024년 3월 6일 OSEN은 전날 공개된 살롱드립2 예고에서 손석구와 장도연이 같은 대사로 패러디했다고 보도했다. 서로 다른 두 제작물의 재현 보도를 확인한 것으로, 원영화나 두 원영상을 직접 본 기록은 아니다.

## 사용 시 주의

음료를 마셨다는 사실이 교제나 신체 접촉에 동의했다는 뜻은 아니다. 실제 고백의 동의를 대신하는 규칙으로 사용하지 않으며 술을 강요하거나 급하게 마시도록 권하지 않는다. 출연자 사이의 실제 연애 관계를 추정하는 근거도 아니다.
