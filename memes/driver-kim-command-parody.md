# 김기사 운전해 말투 패러디

## 뜻풀이

코미디 속 인물이 운전기사를 부르는 독특한 말투를 옮기고, 호칭의 성을 바꾸어 재현하는 패러디다. 실제 직업인의 말투가 아니라 방송의 역할 관계를 빌리는 형식이다.

## 유래와 확산

2006년 11월 22일 스타뉴스는 개그야의 사모님 코너와 광고·시상식의 재현을 설명했다. 특히 광고에서 이나영이 비를 정기사라고 부르며 운전을 요구하는 치환을 구체적으로 소개했다. 한 기사에서 서로 다른 무대의 차용을 보도한 범위만 다루며 원코너·광고·시상식 영상은 직접 보지 않았다. 기사에 함께 등장하는 드라마의 고용 관계 자체를 같은 개그 재현으로 자동 분류하지 않는다.

## 사용 시 주의

실제 운전기사나 노동자를 하대할 때 사용하는 말로 권하지 않는다. 여성이나 특정 계층 전체의 성격을 단정하지 않으며 출연자의 사생활을 덧붙이지 않는다.
