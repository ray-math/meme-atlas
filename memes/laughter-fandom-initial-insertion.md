# ㅋㅋ 뒤에 이름 초성 붙이기

## 뜻풀이

문자 웃음 ‘ㅋㅋ’ 뒤에 좋아하는 그룹 등의 이름 초성을 이어 붙여 웃는 반응 속에 그 대상을 끼워 넣는 말장난이다. 일반적인 문자 웃음과 달리 특정 이름을 떠올리게 하는 초성 결합이 핵심이다.

## 유래와 확산

2026년 1월 13일 캐릿 레터는 코르티스 이름을 결합한 표현과 크래비티·보이넥스트도어 멤버들의 팬 커뮤니티 응용을 소개했다. 해당 매체는 출발 글을 2025년 12월 말로 설명하지만 원게시물은 접근되지 않아 최초 창작일로 확정하지 않는다. 기사 한 군의 사례 설명이며 팬 커뮤니티 원문이나 이미지는 직접 확인하지 않았다.

## 사용 시 주의

이름 초성이 같다는 이유로 특정 개인을 단정하지 않는다. 팬덤 전체의 공통 말투나 사용 규모로 일반화하지 않는다.
