# 쿄레기

## 뜻풀이

격투 게임의 특정 시리즈에서 쿠사나기 쿄의 성능을 낮춰 부르던 별명이다. 캐릭터 이름에 부정적 평가를 붙인 표현으로, 실제 이용자의 능력이나 사람의 가치를 가리키는 말은 아니다.

## 유래와 확산

헝그리앱의 KOF 강캐·약캐 해설은 KOF 2002의 쿄를 이 별명으로 설명하고 소제목에도 직접 사용한다. 기사 한 군에서 역사적 게임 별명의 뜻과 적용을 확인했으며 정확한 기사 발행일은 확인하지 못했다. 댓글 날짜를 발행일로 대신하지 않았고 현재 게임의 성능이나 최초 명명자를 확정하지 않는다.

## 사용 시 주의

캐릭터에 대한 당시 평가와 실제 플레이어에 대한 모욕을 구별한다. 다른 시리즈나 현재 버전에서도 같은 평가가 유지된다고 단정하지 않으며 선택한 캐릭터를 이유로 이용자를 괴롭히지 않는다.
