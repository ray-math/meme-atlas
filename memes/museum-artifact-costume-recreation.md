# 국중박 유물 분장 재현

## 뜻풀이

박물관 유물의 모양이나 자세를 분장·의상·몸짓으로 옮겨 표현하는 참여형 재현 놀이이다. 같은 형식에 서로 다른 유물을 대입하며 대상의 특징을 재해석한다.

## 유래와 확산

2026년 9월 23일 국립중앙박물관 자료는 잉어 모양 연적의 물결과 움직임을 몸으로 표현한 사례를 설명했다. 10월 3일 매일경제는 간돌검·사유상·국새를 재현한 참여도 소개했다. 두 자료가 설명하는 수상작은 겹치므로 독립 사례를 중복 계산하지 않는다. 행사 전체가 아닌 유물 재현 형식만 수록하며 사진과 영상은 직접 확인하지 않았다.

## 사용 시 주의

특정 참가자의 신체나 사생활을 평가하지 않는다. 위험한 자세나 소품을 권장하지 않으며 최초 기원이나 대중적 유행 규모는 확정하지 않는다.
