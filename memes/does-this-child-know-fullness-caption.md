# 배가 부르다는 느낌을 알까요 인용

## 뜻풀이

먹는 장면에 배부름을 아는지 묻는 문구를 붙여 화면과 진지한 말투의 대비를 만드는 인용 형식이다. 확인된 성인의 식사 장면 적용만 다루며 실제 아동의 상황을 설명하는 항목이 아니다.

## 유래와 확산

2021년 6월 25일 NTD뉴스는 히밥의 먹방 영상에 해당 문구의 댓글이 달렸다고 보도했다. 스포츠조선의 별도 기사도 김지혜의 일상 식사 영상에 같은 내레이션과 음악이 쓰였다고 설명한다. 후자의 URL은 2023년 5월 19일이지만 열람 본문에 발행일 표시가 없어 날짜를 확정하지 않는다. 두 보도의 사용 설명을 읽었으며 원댓글·SNS·영상과 최초 광고 기원은 직접 확인하지 않았다.

## 사용 시 주의

빈곤이나 아동의 고통을 조롱하는 표현으로 들릴 수 있으므로 사용 맥락에 주의해야 한다. 과식 도전을 권하거나 실제 영양 상태·식욕을 진단하지 않으며 아동의 사진·신상을 수집하지 않는다.
