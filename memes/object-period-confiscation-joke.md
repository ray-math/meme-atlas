# ○○ 기간 압수

## 뜻풀이

장난이나 실수에 대한 벌인 것처럼 물건 이름과 기간을 붙여 잠시 사용하지 못하게 하겠다고 과장하는 말틀이다. 실제 물건을 빼앗겠다는 지시와 구별하며 자기 행동을 가볍게 돌아보는 농담에도 쓰인다.

## 유래와 확산

2020년 7월 9일 밈과드립의 해설은 압수 대상을 다른 물건이나 동물 간식으로 바꿔 넣는 변형을 설명했다. 2023년 7월 12일 전송된 일요신문 기사는 전날 김동연의 SNS 글에서 휴대전화와 2주라는 기간을 연결한 표현이 사용됐다고 전한다. 원 SNS·댓글·이미지는 직접 확인하지 않았다. 최초 발생 주장과 해설자의 비하 정당화 의견은 채택하지 않으며, 이 항목은 물건·기간을 결합한 가상의 제재 농담으로 제한한다.

## 사용 시 주의

나이·장애·신체적 특징을 겨냥하거나 보조기구를 빼앗는 표현은 사용하지 않는다. 실제 압수나 참여 강요를 권하는 말이 아니다.
