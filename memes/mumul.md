# 무물

질문을 자유롭게 보내 달라는 뜻의 줄임말.

## 뜻풀이

‘무엇이든 물어보세요’를 줄인 말이다. SNS 질문 시간이나 질의응답 콘텐츠를 알릴 때 쓴다. 모든 질문에 답하겠다는 의무나 사생활 공개 동의를 뜻하지는 않는다.

> 예시(창작): 오늘은 그림 도구 이야기 무물 시간!

## 유래와 확산

한국일보는 2022년 질의응답 연재의 편집자 주에서 이 말을 설명하고 실제 코너 이름에 활용했다. 크레이지 자이언트의 신조어 가이드도 질문을 받는 말로 풀이했다.
