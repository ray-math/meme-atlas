# 착붙

## 뜻풀이

옷이나 스타일 등이 사람에게 잘 어울린다는 느낌을 ‘착 달라붙는다’에 빗대어 표현하는 말이다. 여기서는 물리적인 접착이 아니라 어울림을 칭찬하는 용법을 다룬다.

## 유래와 확산

iMBC의 2026년 9월 9일 드라마 소개는 줄임말을 풀이하면서 배우의 조리복 차림에 사용했다. 같은 매체의 3월 26일 기사 제목에도 다른 출연진의 스타일을 수식하는 말로 등장한다. 같은 발행처가 서로 다른 제작물을 소개한 문자 사용 두 건이며, 원영상과 사진을 직접 확인한 것은 아니다. 드라마 소개의 예정된 방송을 이미 완료된 방송으로 보지 않는다.

## 사용 시 주의

외모나 나이를 서열화하는 평가, 체형·색상 진단의 타당성은 이 표현의 근거와 별개다. 특정 스타일을 정답으로 강요하거나 물건이 붙는 모든 상황을 같은 인터넷 용법으로 묶지 않는다.
