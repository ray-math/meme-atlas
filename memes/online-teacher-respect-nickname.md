# 랜선생님

## 뜻풀이

온라인에서 접한 사람에게 유익한 배움을 얻었을 때 선생님에 빗대어 부르는 호칭이다. 실제 교사 자격이나 전문성을 인증하는 말은 아니다.

## 유래와 확산

2025년 2월 인사이트는 신조어 소개와 해당 호칭을 응용한 댓글 반응을 보도했다. 산돌 구름레터도 콘텐츠 제작자를 이 호칭으로 직접 불렀다. 직접 편집 사용 한 군과 소개·반응 보도를 구분하며, 뉴스레터 발행일과 최초 창작자는 확정하지 않는다. 원영상과 원댓글은 직접 확인하지 않았다.

## 사용 시 주의

감사를 표현하는 호칭과 조언의 실제 신뢰성은 구별한다. 온라인에서 친근하게 느낀다는 이유만으로 자격이나 전문 지식을 갖춘 사람으로 단정하지 않는다.
