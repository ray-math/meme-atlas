# 입체 헤더

## 뜻풀이

프로필의 배경과 헤더 경계를 연결해 인물이나 캐릭터가 화면 밖으로 튀어나오는 듯 보이게 꾸미는 이미지 형식이다. 평면 화면에서 경계와 그림자를 이용하는 착시를 다룬다.

## 유래와 확산

2025년 11월 21일 고구마팜은 배경을 맞춘 헤더 제작과 팬들의 결과 공유를 설명했다. 단일 해설을 확인했으며 원 SNS와 이미지는 직접 열람하지 않았다. 최초 제작자와 사용 규모는 검증하지 않았다.

## 사용 시 주의

원사진의 이용 조건과 당사자 동의를 존중한다. 화면 설정에 따라 다르게 보일 수 있으며 실제 입체물이나 서비스의 공식 기능으로 단정하지 않는다.
