# 현망진창

## 뜻풀이

좋아하는 콘텐츠 등에 몰두한 나머지 현실의 일상이 엉망이 된 듯하다는 느낌을 과장하는 말이다. 감상 대상 자체보다 그 여파로 흐트러졌다고 여기는 생활에 초점을 둔다.

## 유래와 확산

2016년 2월 6일 입력된 ZDNet Korea 기사는 넷플릭스 시청과 관련한 SNS 반응을 소개하면서 이 표현의 뜻을 풀이했다. 기사는 같은 달 9일 수정됐으며 URL 속 날짜를 발행일로 삼지 않았다. 확인 범위는 기사 한 건의 용례 설명으로, 원 SNS 게시물을 직접 모은 기록이나 최초 사용 증거는 아니다.

## 사용 시 주의

과몰입과 가까운 문맥에서 쓰이지만 여기서는 일상이 흐트러졌다는 과장에 초점을 둔다. 객관적인 기능 손상이나 중독 진단으로 받아들이지 않으며 콘텐츠가 사람의 생활을 실제로 망가뜨렸다는 인과관계를 단정하지 않는다.
