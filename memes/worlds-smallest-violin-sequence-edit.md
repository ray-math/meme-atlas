# 점점 빨라지는 노래 장면 편집

## 뜻풀이

AJR의 ‘World’s Smallest Violin’ 중 몰아치는 듯한 후반 구간에 맞춰 장면을 시간 순서로 이어 붙이거나 빠른 상황 전개를 연출하는 편집 형식이다. 노래 전체가 아닌 숏폼에서 쓰이는 구간과 장면 배치를 다룬다.

## 유래와 확산

2022년 11월 2일 잼늬 블로그는 해당 곡의 일부가 숏폼 배경음으로 쓰이며 마지막 부분에 시간 순서의 콘텐츠를 맞추는 변형을 설명했다. 국내 설명 자료 1건에 근거한 제한적 항목으로 개별 편집물이나 원음원을 직접 확인한 것은 아니다. 실제 템포 변화를 측정하지 않았으므로 음악 전체의 속도가 계속 상승한다는 사실이나 정확한 구간 길이는 확정하지 않는다.

## 사용 시 주의

노래 가사나 원영상을 그대로 옮기지 않는다. 편집된 시간 전개를 실제 사건의 속도나 순서와 동일하다고 단정하지 않는다.
