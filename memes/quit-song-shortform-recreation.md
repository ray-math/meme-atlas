# 퇴사할게여 숏폼 재현

## 뜻풀이

소연의 곡 퇴사할게여를 자기 상황에 붙이거나 무대 장면을 변형해 보여 주는 숏폼 형식이다. 퇴사 관련 영상에 음악을 사용하는 방식과 자신의 얼굴을 무대 영상에 합성하는 방식은 서로 다른 활용형이며 모든 영상이 같은 안무나 편집을 따르는 것은 아니다.

## 유래와 확산

2026년 9월 11일 이데일리는 이용자의 퇴사 영상에 곡이 활용되는 흐름을 설명했고, 10월 6일에는 소연의 음악방송 무대에 자신의 얼굴을 넣어 재현하는 형식을 보도했다. 9월 9일 티브이데일리도 춤·가창 참여와 곡에 반응한 댓글을 소개했다. 이데일리 두 기사는 같은 매체로 구분한다. 원 SNS와 영상은 직접 확인하지 않았으며 이용자의 실제 퇴사 여부, 최초 제작자와 확산 규모는 확정하지 않는다.

## 사용 시 주의

놀이의 제목이나 댓글을 실제 퇴사 의사로 단정하거나 퇴사를 권유하는 말로 전달하지 않는다. 얼굴 합성은 실제 출연과 구분하고 타인의 얼굴을 동의 없이 쓰거나 오해를 부르는 방식으로 공유하지 않는다.
