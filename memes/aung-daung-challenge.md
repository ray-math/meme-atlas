# 아웅다웅 챌린지

## 뜻풀이
Yyeon의 ‘아웅다웅’에 맞춰 티격태격하는 듯한 펀치 동작을 연기하며 참여자들의 호흡을 보여주는 짧은 춤 형식이다. 실제 싸움이 아니라 장난스럽게 다투는 분위기를 표현한다.

- “이번에는 서로 닿지 않는 동작으로 아웅다웅 챌린지의 장난스러운 느낌을 살려 보자.”

## 유래와 확산
[트렌드어워드의 2026년 2월 24일 소개](https://maily.so/trendaword/posts/mjz6qg3vrwk)는 곡과 펀치 동작을 설명하고 투어스와 제로베이스원의 참여를 각각 소개했다. [인크로스의 소개](https://www.incross.com/ko/insight/report.asp?idx=10748&mode=view)도 황세훈의 안무 구성과 여러 아이돌·크리에이터의 참여를 다뤘다. 해당 페이지의 상단 발행 표시는 2026년 2월 25일이지만 내부 날짜에는 2025년으로 적힌 불일치가 있어 최초 발생일의 근거로 쓰지 않는다.

별개로 [2026년 3월 22일 팬 게시물](https://fanplus.co.kr/community/ive/127472117)은 장원영과 리즈의 팬콘서트 참여 모습을 소개한다. 매체의 참여 소개와 팬의 관찰문을 읽은 것이며, 연결된 원영상이나 공연 이미지를 직접 검증한 것은 아니다. 최초 창작자와 시작일은 확정하지 않는다.

투어스의 ‘OVERDRIVE’에 맞춘 앙탈 챌린지와는 곡·동작이 다른 형식이다. 둘 다 친근한 분위기의 춤으로 소개된다고 해서 같은 밈으로 합치지 않는다.

## 주의
실제로 상대를 때리거나 위협하는 동작으로 사용하지 않는다. 접촉하지 않는 연기로 표현하고 참여·촬영·공유에 동의를 구한다. 영상 속 장난을 근거로 출연자의 실제 관계나 감정을 단정하지 않는다.
