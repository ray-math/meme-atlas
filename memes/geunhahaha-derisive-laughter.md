# 근하하하

## 뜻풀이

웃음소리를 변형해 재미없다고 여기는 내용과 그것을 좋아하는 이용자를 비꼬는 표현이다. 특히 루리웹 이용자를 낮춰 부르는 맥락을 포함하므로 단순히 즐겁게 웃는 소리와 구별한다.

## 유래와 확산

2021년 9월 19일 해설은 집단을 가리키는 글자와 웃음소리를 결합하는 방식, 해당 표현의 비꼼과 음성·리믹스 파생을 설명한다. 해설 본문은 확인했지만 소개된 음성과 영상은 직접 재생하지 않았다. 최초 발생 순서나 전체 유행 규모는 확정하지 않는다.

## 사용 시 주의

어떤 커뮤니티의 실제 취향이나 수준을 객관적으로 나타내는 말이 아니다. 집단 비하와 배척에 쓰일 수 있으므로 타인에게 붙이는 조롱 예문을 제공하지 않는다.
