# APT 댄스 챌린지

## 뜻풀이

로제와 브루노 마스의 ‘APT.’에 맞춰 손동작이나 단체 구성을 재현하는 챌린지다. 같은 곡을 바탕으로 짧은 춤과 소품 연출을 달리하는 형식을 가리킨다.

## 유래와 확산

2024년 10월 29일 W Korea는 르세라핌·(여자)아이들·트레저·안유진 등의 참여를 소개했다. 소품을 이용하는 구성, 여러 사람이 둘러서고 한 사람이 춤추는 구성처럼 서로 다른 재현 사례를 설명한다.

여러 제작 사례를 소개한 기사 한 군에 근거한다. 원영상과 이미지는 직접 확인하지 않았으며 곡의 조회수를 챌린지 참여자 수로 바꾸어 해석하지 않는다. 노래 전체나 술게임 전체를 수록하는 항목은 아니다.

## 사용 시 주의

춤을 위해 음주가 필요하다고 설명하지 않는다. 여러 사람이 움직일 때 안전한 공간을 확보하고 다른 사람의 참여를 강요하지 않는다.
