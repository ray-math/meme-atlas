# 도망가는 NO 버튼 고백페이지

## 뜻풀이

고백 질문이 표시된 장난용 화면에서 거절 버튼에 커서를 대면 버튼이 움직이는 웹페이지 형식이다. 선택지를 정상적으로 고를 수 없다는 반전이 웃음의 장치다.

## 유래와 확산

2026년 5월 19일 캐릿은 밸런타인데이 무렵 이 형식과 국내외 참여를 소개했다. 매체 설명 한 군을 읽었으며 원게시물과 사이트는 실행하지 않았다. 같은 기사에 실린 ‘어떤 선택도 같은 데이트 결과’ 경험은 연관 변형이지 동일 버튼 동작을 검증한 사례가 아니다.

## 사용 시 주의

화면 속 장난은 실제 동의가 아니다. 상대의 거절을 존중해야 하며 동의를 강요하거나 실제 서비스의 선택을 막는 설계로 사용하지 않는다.
