# 한글 써지지 않다 도움 필요

## 뜻풀이

한글 입력이 되지 않는 상황을 어색한 번역체로 도움 요청하는 문구다. 부자연스러운 문장 순서와 표현이 유머로 소비되며 해당 문구를 제목으로 다시 인용하는 방식도 확인된다.

## 유래와 확산

2020년 2월 27일 더쿠의 유머 게시물 제목에서 문구의 재유통을 확인했다. 2021년 11월 26일 밈과드립은 한글 입력 문제를 번역체로 설명한 글의 유통을 소개했다. 원게시물과 첨부 이미지는 직접 확인하지 않았으므로 최초 게시일·정확한 번역 과정·확산 규모는 확정하지 않는다.

## 사용 시 주의

실제 도움 요청이나 한국어에 익숙하지 않은 사람을 조롱하는 데 쓰지 않는다. 작성자 신상과 사생활 추측을 덧붙이지 않으며 기술 안내로 제시하지 않는다.
