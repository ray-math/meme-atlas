# 진짠 줄 알더라 인용

## 뜻풀이

앞서 한 말을 상대가 그대로 믿었다는 식으로 되받으며 말과 의도가 다르다는 인상을 만드는 인용형 표현이다. 앞부분을 다른 행동이나 주장으로 바꾸어 비꼬며, 일반적인 사실 확인과 달리 기존 공개 발언을 알아보게 하는 차용이 핵심이다.

## 유래와 확산

2026년 7월 21일 서울신문은 정치인의 SNS 글에서 문장의 앞부분을 다른 사안으로 바꾼 사례를 보도하고 이를 2021년 공개 발언의 차용으로 설명했다. 확인 범위는 기사에 기록된 문장 변형 한 사례이며 SNS 원문과 원발언 영상은 직접 확인하지 않았다. 최초 인터넷 밈 발생일이나 광범위한 확산은 단정하지 않는다.

## 사용 시 주의

특정인의 말이 실제 거짓이었다는 판정이나 정치적 주장에 대한 동의로 설명하지 않는다. 기사에 인용된 공격적 주장과 재산 세부를 사용 예문으로 재전파하지 않는다.
