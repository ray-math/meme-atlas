# 옹기맨 항아리 게임 실사 패러디

## 뜻풀이

항아리 안에 들어간 게임 캐릭터를 실제 사람이 분장해 재현하는 영상 패러디다. 울주군의 옹기맨은 이 모습을 지역 옹기 홍보와 결합한 사례다.

## 유래와 확산

2025년 5월 1일 경상일보는 울주군 직원이 게임 Getting Over It with Bennett Foddy의 캐릭터를 실사화한 홍보영상을 소개했다. 2026년 4월 29일 YTN 인터뷰에서 출연자는 전년도 옹기마을 배경 영상과 달리 새 영상에서는 게임 속에 들어간 듯한 구성을 만들었다고 설명했다. 같은 지자체의 연속 제작 사례이며 별도 여러 제작자의 확산으로 세지 않는다. 기사와 인터뷰 텍스트만 확인했으며 원영상·게임은 직접 보지 않았다.

## 사용 시 주의

실제 항아리에 몸을 끼우거나 날카로운 도구를 들고 촬영하는 행동을 권하지 않는다. 안전한 소품과 편집으로 표현하고 직원에게 탈의나 출연을 강요하지 않는다.
