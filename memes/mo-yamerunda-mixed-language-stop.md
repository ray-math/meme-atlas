# 모 야메룽다 혼합 말리기

## 뜻풀이

싸움을 그만두라는 한국어 문장에 일본어 발음을 섞어 다툼이나 과열된 논쟁을 말리는 듯 표현하는 패러디 문구이다. 원어 번역보다는 언어가 섞인 자막 말투를 다룬다.

## 유래와 확산

2013년 3월 4일 잉게소는 해당 문구를 한일 혼합 자막 개그의 예로 실었다. 2022년 6월 4일 Door의 건담 해설도 말리는 문구와 커뮤니티 반응 용도를 설명했다. 두 해설을 확인했으며 원영상이나 실제 게시물 적용 두 건을 직접 확인한 것은 아니다. 자료의 원장면 설명이 달라 정확한 회차와 최초 자막은 확정하지 않는다.

## 사용 시 주의

실제 피해나 위험 상황을 농담으로 덮지 않는다. 일본어를 쓰는 사람이나 특정 취향을 조롱하지 않으며 원작 자막의 정확한 번역으로 소개하지 않는다.
