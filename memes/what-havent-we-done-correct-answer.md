# 우리 안 한 게 뭐가 있지? / 어 맞아 정답

## 뜻풀이

아직 하지 않은 일을 물은 다음 뜻밖의 답변을 받고 정답이라 맞장구치는 문답 패러디다. 다정하거나 애교 섞인 말투를 유지한 채 대답의 소재를 바꾸어 웃음을 만든다.

## 유래와 확산

뉴시스의 2024년 6월 19일 기사는 2023년 공개된 짧은 대화 영상이 2024년 패러디로 다시 유통됐다고 설명한다. 같은 기사에 결제로 대답을 바꾼 영상과 턱걸이를 소재로 한 제작 사례가 소개된다. 별개 패러디를 구체적으로 설명하는 기사 한 편을 확인한 것이며, 원영상과 재현 영상을 직접 시청하지 않았다. 최초 발생과 조회수는 독립 검증하지 않았고 최근 1년 유행으로 분류하지 않는다.

## 사용 시 주의

당사자의 실제 관계나 성격을 평가하는 근거로 쓰지 않는다. 말투를 흉내 낼 때 특정인이나 성별을 조롱하지 않도록 맥락을 살핀다.
