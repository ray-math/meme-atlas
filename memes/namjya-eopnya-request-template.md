# 남쟈 없냐 남쟈

## 뜻풀이

원하는 것을 소개해 달라는 요청을 능청스러운 말투로 반복하는 표현이다. ‘○○ 없냐 ○○’의 빈자리를 다른 대상으로 바꾸고 소개를 부탁하는 말을 덧붙이는 방식으로 응용한다.

## 유래와 확산

고구마팜의 2026년 5월 18일 밈 소개는 연차로 대상을 바꾼 표현과 아임미미 제품 콘텐츠, MBC 방송 클립 썸네일의 차용 사례를 다룬다. 한 해설 기사에 담긴 복수 사례이지, 원영상들을 각각 직접 확인한 것은 아니다. 원대화의 작성자나 최초 게시 날짜는 확인하지 않았다.

## 사용 시 주의

실제 개인의 사적인 대화를 그대로 퍼 나르거나 특정인을 연애에 집착하는 사람으로 낙인찍는 데 쓰지 않는다. 상대가 불편해하는 소개 요청을 반복하는 핑계로 삼지 않는다.
