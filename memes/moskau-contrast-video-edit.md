# 모스카우 대비 영상 편집

## 뜻풀이

노래 Moskau를 배경음으로 붙여 서로 다른 장면의 분위기를 과장되게 대비시키는 영상 편집이다. 확인한 해설에서는 평범한 장면 뒤에 거칠거나 뜻밖의 장면을 배치하고 음악으로 전환을 강조하는 방식을 소개한다.

## 유래와 확산

2022년 10월 22일 잼늬 블로그의 한국어 해설에서 이 편집 형식과 음악을 활용한 영상 유형을 확인했다. 설명 한 군을 읽은 것이며 국내 제작 영상 두 건을 독립적으로 확보한 것은 아니다. 원장에 있는 노래 전체가 아니라 대비 편집이라는 하위 범위만 다룬다. 초기 업로드 연혁과 최초 창작자 주장은 별도로 검증하지 않았으며 영상은 재생하지 않았다.

## 사용 시 주의

국적별 성향을 실제 사실처럼 일반화하거나 위험 행동을 흉내 내는 안내로 사용하지 않는다. 가사·영상 전체를 무단 전사하지 않는다.
