# 이대로 가면… 라이더

## 뜻풀이

제목에서 ‘○○ 이대로 가면…’이라며 다음 결과를 예고한 뒤 본문에서 ‘라이더’를 이어 말장난으로 바꾸는 제목 낚시 형식이다. 조건을 나타내는 ‘가면’을 작품 이름의 앞부분으로 바꿔 읽게 한다.

## 유래와 확산

2022년 7월 2일 잼늬 블로그는 제목과 본문을 나누는 방식 및 다른 가면라이더 이미지를 이용하는 변형을 설명했다. 해설 한 군을 읽었으며 예시 이미지나 영상은 직접 보지 않았다. 최초 제작자, 원회차와 확산 시점은 확정하지 않고 해당 문자 말틀만 다룬다.

## 사용 시 주의

작품 전체나 모든 가면라이더 짤을 포괄하지 않는다. 실제 위험·사건을 알리는 긴급 안내처럼 꾸미거나 독자의 클릭을 기만적으로 유도하는 홍보에 쓰지 않는다.
