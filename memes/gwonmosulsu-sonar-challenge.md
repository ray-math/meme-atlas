# 권모술수 쏘냐르 챌린지

## 뜻풀이

드라마 속 ‘권모술수’라는 호칭을 꺼낸 뒤 발음이 비슷한 엔믹스의 ‘Soñar’ 노랫말과 춤으로 이어가는 말소리 연결 챌린지다. 대사 연기가 춤으로 전환되는 데서 웃음을 만든다.

## 유래와 확산

Weverse Magazine은 대사와 음악을 연결하는 형식을 설명했다. 2024년 1월 스타뉴스 보도에서는 엔믹스 배이가 해당 배역을 맡은 주종혁과 함께 챌린지를 촬영한 일을 회고했다.

형식 해설과 참여자의 촬영 회고에 근거한다. 영상은 직접 확인하지 않았으며 최근 1년의 재사용을 검증한 항목은 아니다. 일반적인 권모술수 비난 표현이나 드라마 전체를 포괄하지 않는다.

## 사용 시 주의

배우의 역할과 실제 성격을 혼동하지 않는다. 긴 대사나 가사를 그대로 옮기지 않으며 다른 사람에게 연기나 춤을 강요하지 않는다.
