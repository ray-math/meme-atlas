# 왈랄랄루 반복 응답

## 뜻풀이

특정한 뜻을 전달하기보다 소리의 느낌을 즐기며 쓰는 장난스러운 반응이다. 뜻을 묻는 질문에도 같은 말을 되풀이해 답하면서 설명을 일부러 비껴가는 문자 놀이를 가리킨다.

## 유래와 확산

2022년 10월 5일 잼늬 블로그는 이 표현의 의미를 묻는 글에 같은 말이나 이모티콘으로 답하는 방식을 설명했다. 해설 한 군의 구체 사용 설명을 확인했으며 원댓글은 접근하지 못했다. 최초 사용자와 발생일, 이모티콘 출시일은 확정하지 않는다.

## 사용 시 주의

상대가 실제 설명을 원할 때 반복 답변으로 괴롭히지 않는다. 캐릭터 포즈·팬아트 전체를 포괄하지 않으며 해설에 인용된 그림 수정 공지를 현재 권리자의 사용 허락으로 간주하지 않는다.
