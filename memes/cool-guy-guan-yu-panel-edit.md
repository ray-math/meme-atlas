# 쿨가이 관우 편집

## 뜻풀이

만화 속 관우가 짧게 답하고 중간 과정을 건너뛴 채 다음 행동으로 넘어가도록 편집한 형식이다. 설명이나 절차를 대수롭지 않게 넘기는 태도를 과장하며 대사와 상황을 바꾼 패러디에 쓰인다.

## 유래와 확산

월간디시 2014년 9월호는 요코야마 미츠테루의 삼국지 장면을 생략 편집한 관우 짤과 다른 사건에 응용하는 방식을 설명한다. 해당 페이지의 게시 표시는 2015년 5월 11일로 호수 시점과 다르다. 커뮤니티 운영자 명의 해설 한 건을 읽었으며 원만화와 첨부 이미지는 직접 보지 않았다.

## 사용 시 주의

일반 부정문 전체나 제목 뒤에서 기대를 꺾는 낚시형 그런 거 없다와 구별한다. 실제 폭력을 권하거나 사건 피해자를 조롱하는 예시로 사용하지 않는다. 최초 제작자·최초 게시일과 최근 재유행은 확정하지 않았다.
