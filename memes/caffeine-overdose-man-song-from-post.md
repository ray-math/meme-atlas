# 카페인 과다복용 맨 음악화

## 뜻풀이

카페인을 많이 마신 상태를 과장해 부른 온라인 문구가 보컬로이드풍 노래 제목과 제작 소재로 이어진 사례다. 일상적인 말을 노래 제목처럼 받아들여 실제 음악으로 확장한 인터넷 창작 맥락을 다룬다.

## 유래와 확산

2021년 12월 4일 커뮤니티 글은 해당 문구를 보고 짧은 노래가 만들어졌다고 소개했다. 제작 측 음원 페이지에는 같은 제목의 곡과 2021년 12월 31일 발매일이 표시돼 있다. 소개 글과 제작물 공개 기록을 확인했지만 원트윗과 음원은 직접 확인하지 않았다. 두 자료를 서로 다른 창작자의 재현 두 건으로 세지 않으며 최초 작성자와 정확한 제작 순서, 확산 규모는 확정하지 않는다.

## 사용 시 주의

과다 섭취나 밤샘을 권하는 표현으로 쓰지 않는다. 가사 속 신체 반응을 의학적 설명으로 옮기지 않으며 가사와 음원을 전재하지 않는다.
