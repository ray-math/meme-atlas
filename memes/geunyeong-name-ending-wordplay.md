# 근영체

## 뜻풀이

문장 끝의 소리를 유명인의 이름과 겹치게 바꾸는 인터넷 말투다. 근영처럼 이름이 말끝에 들어가도록 연결하는 장난을 가리킨다.

## 유래와 확산

2005년 9월 6일 주간경향은 문근영의 이름을 말끝에 연결한 표현을 설명하고 나영체와 요환체를 비교 사례로 소개했다. 당대 기사 해설 한 군에 근거하며 실제 원게시물과 최초 작성자는 확인하지 않았다. 삼을 붙이는 일반 종결형과는 이름을 겹친다는 점을 구분한다.

## 사용 시 주의

이름의 당사자가 창작했거나 실제로 사용하는 말투라는 뜻이 아니다. 기사에 등장하는 세대 비판이나 외모 평가를 뜻풀이에 옮기지 않는다.
