# 파묘 얼굴 한자 포스터 합성

## 뜻풀이

영화 파묘의 얼굴 글자 포스터 구성을 다른 인물 사진에 적용하는 팬 편집 형식이다.

## 유래와 확산

2024년 3월 14일 스포츠경향은 아이돌 사진을 포스터처럼 바꾸는 팬덤의 합성 사례를 설명했다. 보도 한 군을 확인했으며 원이미지·편집자·최초 제작일·최근 재유행은 미확인이다.

## 사용 시 주의

실제 문신이나 해당 인물의 종교적 입장을 보여주는 사진으로 오인하게 하지 않는다. 사진 이용 권한과 당사자의 의사를 존중하며 얼굴에 위험한 재료를 쓰는 재현을 권하지 않는다.
