# 본인 방금 상상함 말틀

## 뜻풀이

방금 어떤 사람이 되거나 어떤 일을 하는 상상을 했다고 말한 뒤 현실과의 차이 또는 실제 성취를 덧붙이는 말틀이다. 상상하는 대상과 뒷문장을 바꾸어 게임 후기나 창작물 소개에 적용한다.

## 유래와 확산

2019년 8월 5일 인벤 메이플스토리 게시글은 혼자 보스를 공략하는 상상을 했다는 제목 뒤에 실제로 이뤘다는 내용을 붙였다. 노벨피아의 한 작품 소개도 서로 다른 캐릭터가 되는 상상과 실제 처지를 대비하는 문구를 사용한다. 두 문자 적용 맥락을 확인했으며 노벨피아 소개문의 작성일은 별도 공지 날짜로 추정하지 않았다.

## 사용 시 주의

폭력적 복사문이나 타인을 겨냥한 위협 내용을 예시로 옮기지 않는다. 특정 원문을 최초 기원으로 단정하지 않으며 상상 내용이 실제 사건이라는 의미도 아니다. 게임 영상·만화 이미지·소설 본문은 열람하지 않았다.
