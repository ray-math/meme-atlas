# 좋아 빠르게 가

## 뜻풀이

빠른 추진을 강조하는 정치 홍보 문구를 그대로 반복하거나 실제 결과와 대비해 반어적으로 인용하는 표현이다. 정치적 찬반과 문구를 재사용하는 형식은 구별한다.

## 유래와 확산

2022년 5월 14일 경향신문은 제목에서 문구를 차용하며 당시 선거 쇼츠의 구호·제스처를 밈으로 설명했다. 2024년 12월 17일 한겨레 칼럼도 제목에 문구를 변형해 쓰고 해당 밈을 명시했다. 서로 다른 매체의 제목 적용 두 건을 확인한 것이며 별도의 영상 제작 두 건을 본 것은 아니다. 최초 창작자나 현재 유행 규모는 확정하지 않는다.

## 사용 시 주의

기사에 담긴 정치적 평가나 법률 판단을 표현의 정의로 옮기지 않는다. 사용자의 지지 성향을 추정하거나 특정 지지층을 일반화하지 않으며 욕설처럼 축약한 별칭의 어원을 단정하지 않는다.
