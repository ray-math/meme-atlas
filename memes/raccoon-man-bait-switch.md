# 너굴맨

## 뜻풀이

관심을 끄는 제목 뒤에 너굴맨이 대신 처리했다며 안심시키는 문구를 내놓는 낚시형 반전이다. 기대한 내용을 보여 주는 대신 이미 처리됐다는 선언으로 마무리하는 방식이다.

## 유래와 확산

2020년 6월 밈과드립, 2021년 4월 잼늬 블로그는 제목으로 기대를 만든 뒤 처리·안심 문구로 바꾸는 형식을 설명했다. 2023년 2월 게임조선 기사도 장면을 중간에 가로막는 역할을 비교하며 너굴맨을 언급했다.

근거는 해설 두 건과 기사 내 역할 설명 한 건이다. 원게시물과 이미지·영상은 직접 열람하지 않았으며 블로그가 소개한 별도 계정 사례도 직접 확인한 실제 사용으로 세지 않는다. 최초 게시자나 시작 연도, 이미지 속 동물의 종은 확정하지 않는다. 음악과 회전을 이용하는 다른 라쿤 영상 밈과는 형식이 다르다.

## 사용 시 주의

선정적인 원본이나 실제 폭력을 재현할 필요가 없다. 타인의 게시물을 실제로 삭제하거나 문제를 해결했다는 사실 전달과 구분하며, 피해자의 경험을 가볍게 넘기는 반응으로 쓰지 않는다.
