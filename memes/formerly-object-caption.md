# ○○였던 것

## 뜻풀이

원래 모습이나 기능을 잃은 사물을 이전 이름으로 부른 뒤 ‘였던 것’을 붙여 현재와 과거의 차이를 드러내는 말놀이이다. 망가진 물건이나 기대와 달라진 결과를 과거형 명칭으로 설명하는 문자 형식만 다룬다.

## 유래와 확산

2022년 11월 11일 잼늬 블로그는 사물의 이전 상태를 떠올리게 하는 사용과 게임 이모티콘의 표현 변형을 설명했다. 해설 한 군의 본문을 확인했으며 댓글·이모티콘 이미지와 원작 장면은 직접 보지 않았다. 해설에 제시된 최초 게시일과 작품 기원은 독립 검증하지 않아 확정하지 않는다.

## 사용 시 주의

실제 사망자나 사고 피해자에게 사용하지 않는다. 잔혹한 장면을 재현하지 않으며, 일반적인 과거형 문장 전체가 이 말놀이인 것은 아니다.
