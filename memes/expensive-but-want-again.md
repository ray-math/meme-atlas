# ○○만 원이지만 또 가고 싶은 ○○

## 뜻풀이
비용을 먼저 내세우고도 다시 경험하고 싶다고 말하는 후기형 말틀이다. 식당이나 공연 등에서 느낀 만족을 강조하며, 대상에 따라 가고·먹고·보고·읽고 싶은 것으로 바꿔 쓴다.

- 공연 후기 제목에 금액과 다시 보고 싶다는 말을 붙여 재관람 욕구를 표현하는 경우.
- 음식 게시글에서 메뉴 이름을 넣어 다시 먹고 싶은 마음을 나타내는 경우.
- 뉴스레터 제목에서 ‘가고 싶은’을 ‘읽고 싶은’으로 바꾸어 적용하는 경우.

## 유래와 확산
[2026년 5월 27일 트렌드어워드](https://maily.so/trendaword/posts/x1zg5693oqg)는 더들리의 식당 소개에서 사용해 온 표현이라고 설명하고, 자체 제목에도 다시 읽고 싶은 뉴스레터로 변형했다. 이 자료가 설명하는 원영상은 직접 시청하지 않았으므로 최초 영상과 발생일을 확정하지 않는다. 2026년에 처음 생겼다는 뜻도 아니다.

별도 사용으로 [2026년 6월 29일 NOL 티켓 공연 후기](https://ticket.interpark.com/DaeHakNo/Community/Review_Read.asp?bbsno=10&no=6202721)의 제목과 [2026년 10월 24일 음식 게시글](https://gall.dcinside.com/mgallery/board/view/?id=tenbagger&no=8521301&page=1)의 제목을 직접 확인했다. 앞의 글은 콘서트를 다시 보고 싶은 마음에, 뒤의 글은 라멘을 다시 먹고 싶은 마음에 이 구조를 적용한다. 같은 작성자의 재게시물은 별도 사례로 세지 않았으며, 뉴스레터의 가상 예문과 직접 보지 않은 SNS 캡처도 사용 근거에서 제외했다.

## 주의
후기의 금액은 개인의 표현이나 과장일 수 있어 현재 상품 가격이나 실제 지출의 증거로 쓰면 안 된다. 큰돈을 써야 즐길 자격이 있다는 말이나 과소비 권유로 받아들이지 않는다.
