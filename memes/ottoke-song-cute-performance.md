# 오또케송 애교 재현

## 뜻풀이

짧은 애교송을 출연자마다 다른 말투와 몸짓으로 재현하는 방송 놀이이다. 같은 노래를 각자의 방식으로 수행하는 형식이며, 당황한 사람의 능력을 비하하는 동음 표현과 구별한다.

## 유래와 확산

2020년 5월 20일 iMBC 보도는 NCT DREAM이 주간아이돌의 애교송에 도전한 장면을 소개했다. 같은 해 8월 8일 MBC의 놀면 뭐하니 공식 클립 제목은 싹쓰리의 별도 재현을 명시한다. 같은 방송사 계열 자료의 서로 다른 두 방송 적용이며, 독립 매체 두 군으로 세지 않는다. 영상은 시청하지 않았고 세부 안무와 최초 제작자는 확정하지 않는다. 기사 수정일인 2026년 10월을 발생일로 사용하지 않는다.

## 사용 시 주의

애교를 강요하거나 성적으로 해석하지 않는다. 여성 비하에 쓰이는 동음 표현이나 일반적인 ‘어떡해’ 발음 전체를 포괄하지 않는다.
