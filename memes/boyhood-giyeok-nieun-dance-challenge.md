# 소년시대 기역니은 댄스 챌린지

## 뜻풀이

박남정의 ‘널 그리며’ 포인트 안무를 바탕으로 드라마 ‘소년시대’ 출연진 등이 짧게 재현한 댄스 챌린지다. 옛 춤 전체가 아니라 해당 작품 홍보와 연결된 재현 형식을 가리킨다.

## 유래와 확산

쿠팡 뉴스룸은 2023년 12월 4일 임시완·효진초이·이선빈·이시우·강혜원이 참여한 챌린지 영상을 공개했다고 기록했다. 기존 포인트 안무에 효진초이의 구성을 더한 형식으로 소개된다.

제작·공개 주체의 공식 기록 한 군에 근거한다. 홍보문 속 기대나 인기를 독립적인 유행 측정으로 세지 않았으며 실제 영상과 이미지는 직접 확인하지 않았다. 2023년 공개 기록과 1980년대 춤의 유행 시점은 구분한다.

## 사용 시 주의

드라마의 등장인물과 배우의 실제 성격을 혼동하지 않는다. 모든 기역니은 춤 영상을 이 작품의 챌린지로 분류하지 않는다.
