# 자추

## 뜻풀이

자신이 올린 게시물을 스스로 추천하는 행위를 줄여 부르는 온라인 용어다.

## 유래와 확산

2009년 12월 15일 아시아경제의 신조어 해설은 게시물 추천 방식 가운데 자추의 뜻과 용도를 설명했다. 당대 설명 한 문서를 근거로 기록하며 기사 예문을 실제 특정 게시물의 행동 기록으로 확인한 것은 아니다. 최초 발생자는 확정하지 않는다.

## 사용 시 주의

학교 전형 등 다른 분야의 동명 약어와 구별한다. 모든 자기추천을 부정행위라고 단정하거나 추천 수 조작 방법을 안내하지 않는다.
