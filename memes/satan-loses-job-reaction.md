# 사탄 실직

## 뜻풀이

인간의 지나친 말이나 행동이 악마보다 더 심하다는 식으로 과장하는 반응이다. 사탄이 일자리를 잃거나 한 번 패배했다는 표현으로 그 행동의 정도를 비판하거나 놀라움을 드러낸다.

## 유래와 확산

2021년 4월 개인 해설 글은 ‘실직’과 ‘1패’ 등의 변형과 뜻을 설명했다. 리디에 실린 출판사 소개는 소설이 이 밈을 창작 소재로 활용했다고 밝히며 인간의 악의를 악마에 빗대는 의미를 설명한다. 해당 전자책의 출간일은 2024년 10월 18일이지만 소개문 게시일과는 구분한다.

개인 해설과 출판사의 창작 활용 설명에 근거한다. 출판사 소개가 여러 서점에 실린 것을 독립 원류로 중복 계산하지 않으며 소설 전문과 이미지·영상은 직접 확인하지 않았다. 해설의 가상 예시를 실제 사용 사건으로 세지 않으며 사탄을 소재로 한 모든 농담을 포괄하지 않는다.

## 사용 시 주의

피해자의 사정이나 신체·건강을 조롱하는 말에 동조하는 데 쓰지 않는다. 실제 인물을 범죄자라고 단정하거나 특정 종교 집단을 일반화하는 표현으로 사용하지 않는다.
