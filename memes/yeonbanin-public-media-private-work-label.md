# 연반인

## 뜻풀이

연예인이 아닌 본업이나 일반인 정체성을 유지하면서 방송·온라인 콘텐츠에 자주 등장하는 사람을 가리키는 비공식 호칭이다. 연예인과 일반인을 합친 표현으로 공식 직업 분류는 아니다.

## 유래와 확산

세계일보의 2026년 9월 2일 기사는 이 호칭의 뜻과 본업·방송 활동을 병행하는 사례를 설명했다. 뉴스1의 같은 해 6월 25일 기사에서도 출판사 편집자에게 적용했다. 서로 다른 매체의 문자 용법을 확인했으며 원방송·개인 계정·사진을 직접 본 것은 아니다.

## 사용 시 주의

방송에 등장했다는 이유로 사생활 공개나 신원 추적이 허용되는 것은 아니다. 최초 창안자, 수익과 출연료, 인기 규모는 확정하지 않는다. 팬 활동을 숨기는 일코와는 다른 개념이다.
