# 동엽이 메뉴 취향 호칭

## 뜻풀이

메뉴를 고를 때 엽기떡볶이를 거듭 찾는 사람을 장난스럽게 부르는 말. 일부 재미용 서비스에서는 같은 메뉴를 꾸준히 고르는 유형으로 넓혀 사용한다.

## 유래와 확산

2026년 1월 14일 아시아투데이 해설은 엽기떡볶이를 반복해 찾는 사람에 뜻을 한정한다. 심심랩 메뉴 테스트는 이를 제목과 유형명으로 활용하며 동일 메뉴를 고집하는 모습으로 범위를 넓힌다. 특정 서비스의 확장 용법을 모든 사용자의 공통 뜻으로 일반화하지 않는다. 서비스의 게시일과 실제 결과 공유 사례는 확인하지 않았다.

## 사용 시 주의

음식 취향을 우열이나 건강 상태의 평가로 연결하지 않는다. 방송인 이름에서 비롯됐다는 서비스의 별도 어원설은 확인되지 않아 채택하지 않았다. 기사의 가상 예문은 실제 사용자 발언이 아니며 테스트를 직접 실행하지 않았다.
