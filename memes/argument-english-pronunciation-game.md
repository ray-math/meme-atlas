# 다투다 영어 발음 게임

## 뜻풀이

다투는 상황극 중에도 영어 발음 게임을 이어가며 한국어 대사 사이에 소리가 비슷한 영어 단어를 끼워 넣는 형식이다. 진지해야 할 대화와 게임을 놓지 않는 행동의 어긋남을 웃음으로 만든다.

## 유래와 확산

인크로스의 2025년 11월 19일 소개는 한 창작자의 연인 다툼 상황극과 발음 게임을 결합한 영상을 구체적으로 설명한다. 해당 제작물에 관한 설명 한 군을 확인한 것이며 원영상을 재생하거나 여러 창작자의 재현을 직접 확인한 것은 아니다. 조회수와 최초 유행 시점은 확정하지 않는다.

## 사용 시 주의

실제 관계 갈등을 오락으로 단정하거나 상대의 대화를 무시하는 행동을 권하지 않는다. 출연자의 사적 관계를 추정하지 않으며 영어 발음 실력이나 억양을 조롱하는 형식으로 확대하지 않는다.
