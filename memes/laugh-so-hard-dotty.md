# 개웃겨서 도티낳음

## 뜻풀이
너무 웃기다는 반응을 ‘도티를 낳는다’는 비현실적인 결과에 연결해 과장하는 문구다. 실제 출산이나 해당 인물의 가족관계를 말하는 것이 아니라, 엉뚱한 결과를 붙여 웃음을 표현하는 방식이다.

## 유래와 확산
[2025년 12월 24일 이투데이의 밈 회고](https://www.etoday.co.kr/news/view/2539581)는 이 문구를 웃긴 게시물에 붙이는 과장된 댓글 놀이로 설명했다. 기사가 제시한 발생 경로를 최초 원문까지 검증한 것은 아니다.

문구를 소재로 한 제작 사례도 있다. [푸망의 자체 테스트 소개](https://poomang.com/detail/dotty_test)는 해당 문구를 제목과 제작 설명에 직접 사용한다. 페이지에는 게시일이 표시되지 않아 최근 제작 사례로 계산하지 않는다.

[아블유 팀의 공모전 제출 게임 설명](https://centipedeman.itch.io/soonpoongdotty)은 해당 문구를 이름으로 쓰는 공모전에 제출한 작품임을 밝히며 세 가지 미니게임을 소개한다. 공개일은 2025년 9월 27일로 표시된다. 서로 다른 제작자의 설명을 읽었으며 테스트나 게임을 직접 실행한 것은 아니다.

## 주의
실제 인물의 출생·가족 정보로 오해하게 쓰지 않는다. 임신이나 출산과 관련된 진지한 이야기에 상대의 의사와 무관하게 붙이는 농담은 피한다.
