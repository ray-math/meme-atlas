# 휘리릭·꾸벅 채팅 작별

## 뜻풀이

온라인 대화를 마치며 떠나는 동작이나 인사하는 모습을 글자로 대신 나타내는 표현이다. 휘리릭은 빠르게 사라지는 모습, 꾸벅은 고개 숙여 인사하는 모습을 빌린다.

## 유래와 확산

새국어소식 2002년 6월호는 두 표현이 대화방의 작별 인사를 대신하는 용도로 쓰인다고 설명했다. 당대 언어 해설 한 문서를 근거로 채팅 퇴장 기능만 기록하며 예문을 실제 이용자 대화 기록으로 확인한 것은 아니다.

## 사용 시 주의

일반 의태어의 모든 용법이나 최초 발생 경로까지 포괄하지 않는다. 상대방이 실제로 떠났거나 고개를 숙였다는 사실로 해석하지 않는다.
