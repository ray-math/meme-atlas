# 급발진 반응 비유

## 뜻풀이

대화나 상황에서 갑자기 발끈하거나 반응이 거세지는 모습을 과장해 표현하는 비유다. 실제 차량의 작동이나 사고 원인을 말하는 용법과 구별한다.

## 유래와 확산

iMBC의 2026년 1월 4일 예능 예고는 상대의 평가에 발끈하는 반응에 이 말을 적용했다. 뉴스엔의 같은 해 9월 10일 기사도 다른 프로그램의 극중 인물이 추궁에 격하게 반응하는 모습을 급발진 모드로 표현했다. 서로 다른 프로그램의 예고문 두 군이며, 실제 방송 실행이나 원영상 시청 두 건을 확인한 것은 아니다.

## 사용 시 주의

배우나 출연자의 실제 성격·정신건강·공격성을 판정하는 말로 확대하지 않는다. 비유를 자동차 사고의 원인 설명과 섞지 않는다. 최초 유래와 유행 규모는 미확정이다.
