# 아이유 셀러브리티 티저 캐릭터 합성

## 뜻풀이

아이유의 분홍 드레스 티저 이미지를 영화 캐릭터나 포스터와 합성해 다른 작품 속 인물처럼 보이게 만드는 팬 편집 형식이다.

## 유래와 확산

2021년 1월 18일 에스콰이어는 팬들이 티저를 여러 영화 캐릭터와 합성해 SNS에 올린 사례를 설명했다. 단일 보도에서 확인한 제작군이며 해외 팬의 제작 예고는 실제 완성 사례로 세지 않는다. 원게시물과 합성 이미지를 직접 확인한 것은 아니고 최근 재유행도 확인하지 않았다.

## 사용 시 주의

실제 출연작이나 공식 홍보물로 오해하게 만들지 않는다. 인물 사진과 영화 이미지의 사용 권리를 확인하고 성적·모욕적 합성으로 변형하지 않는다.
