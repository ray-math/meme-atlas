# 셋로그 색·몸짓 맞추기

## 뜻풀이

친구들이 따로 찍은 짧은 일상 영상의 색이나 몸짓을 맞추어 하나의 단체 브이로그처럼 이어 보는 놀이. 셋로그 앱 전체나 모든 일상 공유를 뜻하는 것이 아니라, 서로의 촬영 요소를 맞추는 재사용 형식을 다룬다.

## 유래와 확산

2026년 5월 3일 중앙일보는 친구끼리 옷·사물의 색을 맞추는 무지개 챌린지와 먼저 올린 사람의 동작을 따라 하는 이용 방식을 구체적으로 소개했다. 6월 10일 뉴시스에는 친구들과 짧은 일상을 공유하는 이용자 인터뷰가 실렸다. 후자는 서비스 이용의 보강 근거이지 색 맞추기 챌린지의 별도 제작 사례를 확인한 것은 아니다. 개별 영상과 실제 앱 기능을 직접 실행하지 않았다.

## 사용 시 주의

친구나 주변 사람의 모습, 생활 동선과 사적인 장면은 당사자의 동의 없이 공유하지 않는다. 앱의 보안이나 개인정보 보호를 보증하는 항목이 아니며 기사 시점의 서비스 설명을 현재 사양으로 단정하지 않는다. 모든 참여자에게 같은 주기로 촬영하도록 압박하는 놀이로 만들지 않는다.
