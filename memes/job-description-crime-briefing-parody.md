# 자기 직업 불법적으로 말하기

## 뜻풀이

평범한 업무를 위험한 조직의 임무나 기밀 작전처럼 과장해 설명하는 말놀이. 일의 일부 특징을 낯선 단어로 바꾸어 익숙한 직업이 수상하게 들리도록 만드는 형식이며 실제 범죄를 고발하는 문장이 아니다.

## 유래와 확산

2026년 6월 10일 고구마팜은 직업을 과장하는 형식과 댓글의 직종별 응용을 소개했다. 심심랩은 이를 일상 상황의 말하기 방식으로 바꾼 ‘직업 과장 브리핑’ 테스트를 제공한다. 기사 속 응용 설명과 별도 서비스의 실제 제목·유형 구성을 확인했으며, 원 SNS 댓글이나 테스트 결과를 직접 생성한 것은 아니다. 서비스의 게시일과 최초 발생 시점은 확인하지 않았다.

## 사용 시 주의

실존 인물이나 기관이 불법 행위를 했다는 주장처럼 보이지 않도록 농담 맥락을 분명히 한다. 실제 범죄·피해·직업군을 비하하거나 과장된 문장을 사실 확인 자료로 사용하지 않는다. 신체 동작을 붙이는 직종별 호신술 상황극이나 취업 상태를 다른 직함으로 부르는 자기소개와 구별한다.
