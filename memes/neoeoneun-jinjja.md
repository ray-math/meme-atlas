# 너어는 진짜

## 뜻풀이

상대를 부르는 ‘너’를 늘여 적어, 황당하거나 얄미운 행동에 말문이 막힌 듯 반응하는 문자 표현이다. 뒤의 평가를 생략해 가볍게 타박하거나, 좋아하는 대상에게 감탄하면서 장난스럽게 원망하는 말투로도 쓴다.

- 할 일을 미루고 다른 일을 했다는 말에 짧은 타박으로 붙일 수 있다.
- 팬 게시물에서는 상대의 매력에 감탄하는 반응에도 쓰였다.
- 같은 문장이라도 친근한 놀림인지 실제 불만인지는 앞뒤 맥락에 따라 달라진다.

## 유래와 확산

2026년 10월 9일 더쿠 원필 게시판의 글은 물컵을 바라보는 모습에 대한 반응을 적으면서 제목에 이 표현을 사용했다. 같은 달 25일 예준 게시판에서는 공연 관련 링크를 공유하며 호감을 드러내는 본문에 사용했다. 서로 다른 대상과 글에서 확인되는 텍스트 반응이지만 익명 작성자들의 실제 신원이 서로 다른지는 확인하지 않았다.

코네의 별도 글에서는 작업보다 게임을 하고 있다는 작성자의 말에 이 표현으로 답한 댓글이 확인된다. 해당 페이지의 게시 날짜는 확인하지 못했으므로 최근 사용 건수에는 넣지 않는다.

확인한 범위는 글자 늘이기를 활용한 반응 말투다. 특정 인물이나 이미지가 원조라는 주장, 최초 사용 시점, 전체 유행 규모는 이 자료들로 확정하지 않는다. 링크된 영상과 이미지는 확인하지 않았으므로 영상 속 실제 행동이나 발언을 검증한 사례로 보지 않는다.

## 사용 시 주의

상대에게 직접 쓰면 나무라거나 깔보는 말처럼 들릴 수 있다. 친근한 관계에서도 상대의 불편함을 확인하고, 실제 갈등이나 잘못을 지적해야 할 때는 구체적인 내용을 말한다. 호감 표현의 ‘유죄’ 같은 과장도 실제 범죄 주장과 혼동하지 않는다.

- [더쿠 예준 게시판의 공연 반응 글](https://theqoo.net/yejun/4386301502): 2026년 10월 25일. 링크 공유 뒤에 붙인 호감 반응을 확인했다. 공연 영상 자체는 미확인.
