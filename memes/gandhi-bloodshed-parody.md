# 간디 유혈사태

## 뜻풀이

게임 《문명 5》의 간디를 위협적인 협상가처럼 표현하는 패러디다. 비폭력의 이미지와 공격적인 게임 캐릭터라는 대비를 이용하며, 관련 문구의 소리를 인물 이름으로 바꾸는 합성도 보도됐다.

## 유래와 확산

2010년 10월 27일 아이뉴스24는 간디 캐릭터에 유희열의 얼굴을 합성하고 이름과 ‘유혈사태’의 비슷한 소리를 연결한 이미지를 소개했다. 같은 해 12월 31일 게임동아도 게임 이용자들 사이에서 유혈사태와 공격적인 간디를 연결한 표현이 유행했다고 설명했다.

확인한 것은 당시 합성 사례의 보도와 게임 문화 설명이다. 원이미지와 게임 화면은 직접 확인하지 않았으며 실제 게임의 정확한 대사나 번역, 프로그램 오류에서 시작됐다는 기원은 확정하지 않는다. 최초 합성자와 현재 확산 규모도 단정하지 않는다. 역사적 인물의 실제 행적 전체를 설명하는 항목은 아니다.

## 사용 시 주의

게임 캐릭터 풍자를 실제 인물이나 집단에 대한 폭력 위협으로 바꾸지 않는다. 역사적 사실과 게임 설정, 이용자의 합성을 구분하며 출연자의 외모를 조롱하는 설명도 피한다.
