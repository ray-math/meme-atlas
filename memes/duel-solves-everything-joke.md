# 듀얼 만능주의

## 뜻풀이

서로 다른 문제도 결국 카드게임 승부로 해결하려는 설정이나 사고방식을 웃음거리로 부르는 표현이다. 유희왕의 과장된 문제 해결 방식을 설명하는 인터넷 명칭으로 쓰인다.

## 유래와 확산

2021년 5월 19일 잼늬 블로그는 유희왕에서 여러 상황을 듀얼로 해결하는 설정을 이 이름으로 설명했다. 독립 해설 한 건을 통해 명칭과 뜻을 확인했으며 개별 장면이나 국내 제작물 여러 건을 직접 확인한 것은 아니다. 최초 명명자와 정확한 확산 시점은 미확정이며 삽입 이미지·영상은 보지 않았다.

## 사용 시 주의

현실의 갈등을 게임 승부로 해결해야 한다는 주장이 아니다. 작품의 설정을 설명하는 농담과 실제 분쟁 해결 절차를 구분한다.
