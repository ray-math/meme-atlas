# 러시아에서는 ○○가 당신을

## 뜻풀이

평소 행동하는 쪽과 그 행동을 받는 쪽을 뒤집어 엉뚱한 상황을 만드는 문장 놀이이다. ‘러시아에서는’이나 ‘소련에서는’ 같은 도입부를 붙이는 형식으로 알려졌지만, 실제 국가의 생활이나 언어 문법을 설명하는 말은 아니다.

## 유래와 확산

2010년 9월 16일 한국어 피규어 촬영 후기에서는 인형이 트럭을 타는 문장과 트럭이 인형을 타는 문장을 대비하고, 이를 러시아식 유머라고 직접 이름 붙였다. 여기서는 한 제작자의 글에서 주체·대상을 뒤집은 텍스트 적용을 확인한 범위만 다룬다. 첨부 사진이나 영상은 직접 확인하지 않았으며, 최초 기원이나 국내 확산 규모를 확정하지 않는다. 해당 글의 러시아어 문법 설명은 근거로 채택하지 않는다.

## 사용 시 주의

국가나 국적 집단의 실제 특성을 단정하는 표현이 아니다. 민족 비하나 실제 피해를 웃음거리로 만드는 용법으로 확대하지 않는다.
