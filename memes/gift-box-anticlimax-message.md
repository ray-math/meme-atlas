# 선물상자 허무메시지

## 뜻풀이

선물처럼 보이는 링크를 보내고 상자가 열리는 연출 뒤에 평범하거나 싱거운 말을 드러내는 웹 장난이다. 특별한 내용을 기다리게 한 뒤 짧은 인사 같은 말을 보여주는 기대와 결말의 차이가 핵심이다.

## 유래와 확산

인크로스의 2026년 9월 2일 소개는 개발자의 시연과 댓글 반응을 설명한다. 해당 기사 한 군의 본문을 확인했으며 원사이트를 실행하거나 시연 영상을 재생하지 않았다. 조회수와 이용 규모는 별도 검증하지 않아 수록하지 않는다.

## 사용 시 주의

실제 선물이나 금전 제공을 약속하는 링크와 혼동시키지 않는다. 수신자가 원하지 않는 반복 전송이나 낯선 사이트 접속 유도는 피한다.
