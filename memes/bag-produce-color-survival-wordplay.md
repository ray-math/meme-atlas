# 가방듀스101

## 뜻풀이

가방 색상별 출시 여부를 아이돌 서바이벌의 데뷔와 탈락에 빗대어 부르는 말놀이이다. 원하는 색이 생산되기를 응원하는 상황을 경연처럼 이야기한다.

## 유래와 확산

2025년 10월 17일 더쿠 게시물은 가방듀스101을 제목으로 삼고 특정 보스턴백의 색상 일부를 ‘탈락’이라고 표현했다. 같은 해 11월 21일 고구마팜 기고문은 이 상품의 색상별 생산을 데뷔에 빗대어 응원하고 패자부활전 경과를 공유하는 형식을 설명했다. 커뮤니티 적용과 해설을 확인한 범위이며, 인용된 원 X 게시물과 이미지는 직접 열람하지 않았다. 최초 명명자와 실제 주문량은 확정하지 않는다.

## 사용 시 주의

특정 상품을 둘러싼 언어 놀이를 설명한 것으로, 품질·생산 여부·예약 조건의 검증이나 구매 권유가 아니다. 모든 공동구매나 색상 투표를 같은 밈으로 묶지 않는다.
