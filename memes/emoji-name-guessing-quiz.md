# 이모지로 이름 맞히기

## 뜻풀이

여러 이모지를 조합해 이름을 수수께끼처럼 나타내고 댓글에서 정답을 맞히게 하는 형식이다. 보는 사람도 자기 이름을 같은 방식의 문제로 바꾸어 참여한다.

## 유래와 확산

2026년 10월 20일 고구마팜은 이모지 조합 영상과 시청자가 자기 이름으로 퀴즈를 만드는 댓글 응용을 설명했다. 단일 해설에서 확인한 형식이며 연결된 원게시물·이미지나 실제 조회수를 직접 검증하지 않았다. 신규 제품 공개 같은 활용 제안은 완료된 사례로 세지 않는다.

## 사용 시 주의

타인이나 아동의 실명·개인정보를 동의 없이 문제 소재로 공개하지 않는다. 이모지와 닮은 외모를 소개하는 놀이 및 표정 따라 하기와 구별하며 답변을 강요하거나 틀린 사람을 조롱하지 않는다.
