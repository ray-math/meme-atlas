# 넘어지는 와플 캐릭터 합성

## 뜻풀이

세워 놓은 와플이 넘어지는 짧은 영상에 캐릭터를 끼워 넣는 합성 형식이다. 캐릭터가 와플에 가려지거나 와플을 미는 듯 보이게 하며, 갑자기 장면이나 소리가 끊기는 효과를 이용한다.

## 유래와 확산

잼늬 블로그와 트렌드어워드의 한국어 소개 글은 와플 영상과 캐릭터를 결합한 여러 변형을 설명한다. 두 해설 본문을 확인했지만 국내 제작자 두 명의 작업을 직접 확인한 것은 아니다. 블로그의 게시 표시와 본문 회고 시점이 일치하지 않아 정확한 확산 월은 채택하지 않았다. 원영상과 임베드 영상은 재생하지 않았다.

## 사용 시 주의

실제 사람의 피해를 조롱하는 합성으로 확대하지 않는다. 음식 전체나 다른 와플 관련 유행을 포함하지 않으며 영상 사용 권리가 자동으로 허용되는 것도 아니다.
