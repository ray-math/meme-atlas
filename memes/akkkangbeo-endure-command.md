# 악으로 깡으로 버텨라

## 뜻풀이

스스로 고른 상황이라는 이유를 들어 힘들어도 버티라고 요구하는 반응 말틀이다. 줄임말로 ‘악깡버’라고도 하며 선택한 대상을 앞에 붙이는 형태가 쓰인다.

## 유래와 확산

2021년 8월 밈과드립 해설은 선택한 대상과 버티라는 명령을 결합하는 형식을 설명했다. 2022년 9월 아시아경제 칼럼은 이를 ‘누칼협’과 함께 선택의 책임을 전가하고 타인의 어려움에 공감을 거두는 언어로 분석했다.

두 해설 자료에 근거한다. 자료의 설명용 예문을 별개의 실제 사용자 발화로 세지 않으며 원게시물은 직접 확인하지 않았다. 특정 군대 경험이나 가혹행위 서사를 사실로 확정하지 않는다. 강요 여부를 반문하는 말과 버티라고 명령하는 말의 형식 차이에 한정한다.

## 사용 시 주의

부당한 대우나 위험한 상황을 참으라고 강요하는 데 쓰지 않는다. 본인이 선택했다는 이유만으로 도움을 요청할 권리가 사라지는 것은 아니다.
