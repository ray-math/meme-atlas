# 책갈피 랜덤깡

## 뜻풀이

문학 작품 표지를 활용한 빵의 포장을 열어 무작위 책갈피를 확인하고 결과를 공유하는 개봉 놀이이다. 빵을 먹는 과정보다 어떤 책갈피가 나왔는지 확인하는 데 초점을 둔다.

## 유래와 확산

2026년 8월 29일 중앙일보는 구매자들이 포장을 열어 책갈피를 확인하고 사진을 공유하거나 중복 결과에 반응하는 모습을 보도했다. 기사 한 군의 구체 사례이며 SNS 원게시물이나 영상은 직접 확인하지 않았다. 음반 개봉 놀이와는 개봉이라는 큰 가족을 공유하지만 확인 대상과 결과가 다르다.

## 사용 시 주의

희소성을 부풀리거나 반복 구매를 권하지 않는다. 구매량·판매 통계와 최초 발명자는 이 항목에서 확정하지 않는다.
