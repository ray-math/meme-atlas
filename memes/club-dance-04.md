# 04년생 클럽춤

## 뜻풀이

손을 얼굴 가까이에 두고 좌우로 리듬을 타는 춤을 짧은 영상으로 따라 하는 밈이다. ‘04년생 클럽춤’이나 당시 클럽에서 유행하는 춤이라는 이름으로 소개됐으며 특정 출생연도 사람들의 실제 행동 전체를 뜻하지 않는다.

## 유래와 확산

2023년 1월 밈과드립은 특정 음악 구간에 손동작과 리듬을 맞추는 형식과 패러디 현상을 설명했다. 같은 해 3월 잼늬 블로그도 동작을 해설하고 가상 캐릭터가 같은 구조로 춤추거나 짧은 상황극을 덧붙인 변형을 소개했다.

두 글은 춤 형식의 해설 자료이며 서로 다른 실제 제작 원문 두 건을 직접 검증한 것은 아니다. 영상과 이미지는 열람하지 않았다. 최초 제작자나 정확한 유행 시작일, 현재 인기와 참여자 수는 확정하지 않으며, 블로그에 적힌 세대 심리 추측도 채택하지 않는다. 2023년 자료로 확인한 과거 항목이다.

## 사용 시 주의

표제의 출생연도를 근거로 특정 연령집단을 조롱하지 않는다. 실제 나이나 장소 출입 자격을 추정하는 표현으로 쓰지 않으며, 다른 사람이 원하지 않는 춤을 강요하지 않는다.
