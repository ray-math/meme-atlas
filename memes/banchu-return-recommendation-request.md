# 반추·반사추천

## 뜻풀이

온라인 추천 상황에서 상대에게 추천을 돌려 달라고 요청하는 반사추천의 줄임말이다. 되새긴다는 일반어 반추와는 다른 뜻이다.

## 유래와 확산

2009년 12월 15일 아시아경제의 신조어 해설은 추천 이벤트 등의 맥락에서 이 표현을 설명했다. 당대 설명 한 문서에 한정하며 기사 속 예시를 실제 특정 게시물의 대화로 세지 않는다. 최초 사용 시점과 확산 규모는 확인하지 않았다.

## 사용 시 주의

특정 서비스의 규칙을 판단하거나 추천 교환을 권장하는 안내로 쓰지 않는다. 일반적인 반성이나 회고를 뜻하는 문맥과 혼동하지 않는다.
