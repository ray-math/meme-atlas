# 국기 그리기 변신 챌린지

## 뜻풀이

허공에 국기를 그리는 동작 뒤에 해당 나라를 상징하는 차림이나 이미지로 전환하는 숏폼 형식이다. 국내에서는 태극기 챌린지라는 이름도 쓰였다.

## 유래와 확산

2024년 12월 23일 대학내일은 해외 플래그 챌린지의 국내 적용과 영상 전환 형식을 설명했다. 이 해설 본문만 확인했으며 원영상·최초 제작자·최근 재유행은 검증하지 않았다.

## 사용 시 주의

국가별 외모나 문화를 하나로 단정하거나 다른 나라를 비하하는 용도로 사용하지 않는다. 편집 전후의 인물 동의와 이미지 이용 권한을 존중한다.
