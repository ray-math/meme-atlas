# 길을 잃었다 분홍신 반응

## 뜻풀이

길을 헤매거나 말의 흐름이 엉뚱한 곳으로 샜을 때 아이유의 ‘분홍신’ 한 구절을 떠올리며 쓰는 반응이다. 실제 길 찾기와 이야기 방향을 잃었다는 농담 양쪽에 적용된다.

## 유래와 확산

인사이트는 2020년 11월 기사에서 그해 3월 공개된 게임 영상 속 미나가 길을 잃자 해당 노래를 불렀다고 전했다. OSEN은 2024년 11월 19일 김영철이 산만하게 이어지는 SNS 글을 마무리하면서 가수와 곡명을 밝히고 같은 표현을 썼다고 보도했다.

서로 다른 두 사용 사건을 전한 기사에 근거한다. 기사 게시일을 노래나 밈의 발생일로 삼지 않으며 원영상·SNS·이미지는 직접 확인하지 않았다. 일반 문장 전체가 아니라 특정 노래를 인용하는 반응으로 범위를 한정한다.

## 사용 시 주의

가사 전체를 옮기거나 음원을 무단 배포하지 않는다. 모든 길 찾기 실패 발언이 노래를 인용한 것이라고 단정하지 않는다.
