# 병진: 비속어 철자 변형

## 뜻풀이

모욕적인 비속어의 철자를 바꾸어 직접적인 표기를 피하는 인터넷 표현이다. 표기가 달라져도 상대를 낮추는 뉘앙스가 없어지는 것은 아니다. 같은 이름을 가진 사람이나 영화 속 인물을 가리키는 용례와 구분한다.

## 유래와 확산

2008년 2월 1일 헤럴드경제의 인터넷 유행어 해설은 이 표현을 직접 표기를 피한 철자 변형의 사례로 들었다. 해설 한 군에서 확인한 역사적 용법으로, 원댓글을 직접 열람한 것은 아니다. 특정 영화 대사의 말틀과 동일 항목으로 연결하지 않으며 최초 창작자·시작일은 확정하지 않는다.

## 사용 시 주의

철자 변형을 이용해 상대에 대한 모욕을 정당화하지 않는다. 동명 인물이나 실제 의학적 상태와 연결하지 않으며, 표현이 완곡해 보여도 장애 비하와 괴롭힘의 문제가 사라지는 것은 아니다.
