# ○○가 잘되는 사회를 만들든가

## 뜻풀이

불만스러운 상황을 두고 ‘○○가 잘되는 사회를 만들든가’라고 요구한 뒤 다른 사람이 감동한 듯한 짧은 답글로 호응하는 말틀이다. 대상을 바꾼 요구와 과장된 응답의 조합을 다룬다.

## 유래와 확산

2021년 5월 24일 밈과드립은 방송 발언에서 이어진 문장 치환과 답글 조합을 구체적으로 설명했다. 해설 한 군을 확인했으며 방송 원영상과 개별 댓글 이미지는 직접 확인하지 않았다. 글의 정치적 평가와 책임 해석은 채택하지 않으며 최초 유행일은 확정하지 않는다.

## 사용 시 주의

취업난이나 어려움을 겪는 사람의 감정 표현을 조롱하지 않는다. 출처의 정치적 견해를 사실 판정으로 삼거나 상대의 정당한 문제 제기를 무시하는 답변으로 사용하지 않는다.
