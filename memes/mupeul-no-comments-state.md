# 무플

## 뜻풀이

인터넷 게시물에 댓글이 달리지 않은 상태를 이르는 말이다.

## 유래와 확산

2006년 3월 14일 매일신문은 댓글 문화를 설명하면서 무플의 뜻을 풀고 당시 TV 프로그램에서 소개한 내용을 전했다. 신문 해설 한 군에 근거하며 방송명과 원방송, 실제 게시판 사례는 직접 확인하지 않았다. 최초 발생과 사용 규모는 확정하지 않는다.

## 사용 시 주의

댓글 유무를 사람이나 글의 가치와 동일시하지 않는다. 관심을 얻으려는 악성 댓글을 정당화하는 표현으로 쓰지 않는다.
