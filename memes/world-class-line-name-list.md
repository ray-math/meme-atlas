# 월클라인

## 뜻풀이

세계적으로 유명한 인물들의 이름을 나열한 뒤 자기 자신이나 예상 밖의 이름을 같은 줄에 끼워 넣는 말놀이다. 실제 업적의 객관적인 순위를 정하기보다 어울리지 않는 조합을 과장해 웃음을 만든다.

## 유래와 확산

캐릿의 트렌드 레터는 유명인 목록 뒤에 뜻밖의 이름을 넣는 응용을 설명했다. 페이지에 정확한 날짜 필드는 없으며 본문에 2023년 관련 문맥이 있다. 2024년 7월 OSEN도 이 표현과 사진에 대한 SNS 반응을 보도했다.

해설 한 군과 별도 보도 한 군에 근거한다. 원 SNS와 영상은 직접 열람하지 않았으며 정확한 최초 게시자나 확산 시작일은 단정하지 않는다.

## 사용 시 주의

농담으로 만든 이름 목록을 실제 경력이나 국제적인 평가의 근거로 제시하지 않는다. 타인을 깎아내리거나 허위로 친분·동등한 지위를 암시하지 않는다.

## 확인한 자료

- [캐릿의 트렌드 레터](https://www.careet.net/Newsletter/Detail/1477): 정확한 게시일 미확정. 이름 나열 뒤 삽입하는 형식 설명.
- [OSEN의 표현과 SNS 반응 보도](https://www.osen.co.kr/article/G1112371550): 2024년 7월 6일.
