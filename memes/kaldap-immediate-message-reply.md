# 칼답

## 뜻풀이

메시지를 받고 곧바로 답하는 것을 가리키는 말이다.

## 유래와 확산

2021년 1월 작성된 온라인 플랫폼 노동 실태조사 보고서는 참여자 인터뷰에 칼답이라는 말을 싣고 즉시 응답으로 풀었다. 이 보고서는 2월 1일 토론회 자료집에 수록됐다. 인터뷰 수록 한 군에 근거하며 원녹음이나 실제 메시지는 직접 보지 않았다. 문서 작성일과 토론회 날짜를 웹 게시일로 바꾸어 적지 않는다.

## 사용 시 주의

답장 속도로 상대의 애정·성실성·업무 능력을 판단하지 않는다. 보고서 속 거래 성과와 수입 주장은 표현의 뜻에 포함하지 않는다.
