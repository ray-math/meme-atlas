# 너반시

## 뜻풀이

드라마 킬미, 힐미의 고백 대사를 팬들이 줄여 부르는 이름이다. 대사를 언급하거나 다른 콘텐츠에서 비슷한 말을 발견했다는 소감을 나눌 때 사용하는 약칭이며 모든 고백 문장을 포괄하지 않는다.

## 유래와 확산

지성 갤러리의 팬 단어장은 너에게 반한 시간의 줄임말로 풀이한다. 단어장은 2015년 3월 게시 표시와 달리 제목에 6월 버전과 수정 중 표시가 있어 해당 설명의 최초 기입일은 단정할 수 없다. 2025년 10월 1일 킬미, 힐미 갤러리 글은 예능에서 대사를 발견했다는 제목에 이 약칭을 썼다. 제목의 직접 호칭 사용만 확인했으며 첨부 이미지와 방송 재현 장면은 확인하지 않았다.

## 사용 시 주의

팬 내부 약칭이므로 맥락을 모르는 사람에게는 작품과 대사를 풀어 설명한다. 팬의 관찰 글을 해당 방송 장면이나 출연자의 의도를 직접 검증한 자료로 바꾸어 인용하지 않는다.
