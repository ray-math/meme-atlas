# 왕과 사는 남자 제목 바꾸기

## 뜻풀이

영화 《왕과 사는 남자》의 제목에서 낱말을 바꾸어 다른 장소나 업무를 소개하는 패러디 형식이다. 원제의 말맛과 구성을 남기면서 홍보 대상과 이어지는 단어를 끼워 넣는다. 영화의 모든 장면 재연이나 관련 유행을 한데 묶은 항목은 아니다.

- 관세청의 세관 신고 안내에는 ‘왕과 세는 남자’라는 제목이 사용됐다고 보도됐다.
- 영화 《폭설》의 홍보 포스터는 기차역 배경과 연결해 ‘역과 사는 남자’로 바꾼 사례다.
- 달성군의 육신사 소개 영상은 ‘육신사에 사는 남자’라는 제목을 붙였다고 보도됐다.

## 유래와 확산

2026년 지자체·공공기관 영상과 다른 영화의 홍보물에서 제목 치환이 각각 확인된다. 서울신문은 3월 달성군의 적용을, 택스워치는 4월 관세청의 적용을, 스포츠동아는 10월 쇼박스의 포스터를 전했다. 서로 다른 제작 주체의 사례이지만, 이번에 직접 읽은 자료는 이를 설명하는 기사 본문이다.

원 영상·공식 업로드 게시물·포스터 이미지 자체는 직접 확인하지 않았다. 기사 날짜와 영상 공개일을 구분하며, 세 사례만으로 최초 제작자나 일반 이용자 전체의 유행 규모를 확정하지 않는다.
