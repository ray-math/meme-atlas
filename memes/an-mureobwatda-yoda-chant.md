# 안 물어봤다 요다야

## 뜻풀이

물어보지 않았다는 말을 요다라는 이름과 반복 음절로 이어 부르는 장난스러운 구전 문구다. 짧게 관심 없음을 표시하는 축약어와 달리 말의 운율을 계속 잇는 형식이 특징이다.

## 유래와 확산

2015년 8월 힙합플레이야 게시글과 댓글에는 각자가 기억하는 끝말을 직접 적고 비교하는 대화가 남아 있다. 2026년 5월 트렌드어워드 에디터도 지금도 마음속으로 부른다며 해당 문구를 사용했다.

두 플랫폼의 문자 재현과 회고를 확인했다. 지역별 사용 빈도나 최초 창작자, 원곡 선율은 확정하지 않으며 음성·영상은 직접 확인하지 않았다. 끝말이 여러 형태로 전해졌으므로 하나만 원형으로 단정하지 않는다.

## 사용 시 주의

상대의 말을 무시하거나 외모를 놀리는 데 쓰지 않는다. 구전 놀이의 설명과 실제 사람에 대한 모욕을 구별한다.
