# 허경환 유행어 줄서기 릴레이

## 뜻풀이

여러 사람이 한 줄에 서서 허경환의 유행어를 차례로 외치는 협동형 챌린지다. 한 사람의 긴 메들리나 언발란스 춤 전체를 뜻하지 않고, 참여자가 대사를 나누어 이어가는 형식을 가리킨다.

## 유래와 확산

2026년 1월 20일 스포츠경향은 허경환이 SNS 챌린지 영상을 보며 반응한 콘텐츠를 소개하고 줄서기와 순차 발화 방식을 설명했다. 보도 본문 한 군을 확인했으며 영상 속 인물·대사 순서·원편집자는 직접 검증하지 않았다. 개별 유행어의 최초 발생과 릴레이 유행의 시작일은 구분한다.

## 사용 시 주의

참여자의 발화와 촬영에 대한 동의를 존중한다. 실패한 사람을 조롱하거나 특정 억양을 지역 비하에 사용하지 않는다.
