# 하찮은 AI 낙서 변환

## 뜻풀이

사진이나 로고를 일부러 서툴게 그린 낙서처럼 다시 만들고 공유하는 AI 이미지 놀이이다. 매끈한 원본과 삐뚤고 어설픈 그림의 대비를 즐기는 형식이며 AI 이미지 생성 전체를 뜻하지 않는다.

## 유래와 확산

2026년 5월 6일 아시아경제는 국내 창작자의 예능 장면·고양이 이미지 변환과 이용자들의 공유를 보도했다. 5월 22일 디지털 인사이트는 자체 로고와 뉴스레터 헤더에 적용한 결과를 캡션으로 소개했다. 후자의 여러 대상은 한 매체의 자체 활용군으로 묶으며, 실제 이미지와 생성 서비스는 직접 확인·실행하지 않았다. 최초 발생일과 유행 규모, 현재 제공 기능을 확정하지 않는다.

## 사용 시 주의

변환 결과를 실제 손그림이나 원작자의 제작물로 속이지 않는다. 원본 이미지의 권리와 인물의 동의를 확인해야 하며, 타인을 모욕하는 변형에 사용하지 않는다.
