# 난리도 아니햐

## 뜻풀이
이수지가 코미디에서 보여준 과장된 억양을 흉내 내며 상황이 대단하거나 어수선하다는 반응을 전하는 표현이다. 말끝을 늘이거나 ‘아니햐’처럼 적어 말투를 살리며, 대사를 노래와 동작으로 바꾼 챌린지로도 쓰인다.

- 뉴스레터가 새 트렌드와 이수지의 인기를 소개하는 문장에 이 말투를 직접 차용한다.
- 충청북도의 청남대 모노레일 홍보 영상에 이 문구와 패러디가 사용된 사례가 소개된다.

## 유래와 확산
[응답하라 마케팅 2026년 5월 26일 글](https://maily.so/marsinmarine/posts/mjz6kk8yrwk)은 SNL 코리아의 ‘스마일 클리닉’에서 이수지가 연기한 캐릭터의 말투를 설명하고, 부제와 편집자 문장에 직접 활용한다. [잉크닷의 2026년 5월 3주 분석](https://inkdot.kr/20260503_3/)은 충청북도 관광시설 홍보 영상의 제목과 밈 패러디를 구체적으로 기록한다. 정확한 분석 글 발행일과 원영상은 직접 확인하지 않았으므로 확인 범위는 뉴스레터의 실제 차용과 별도 매체가 보고한 기관 적용이다. 캐릭터 직책과 최초 유행 시점은 단정하지 않는다.

## 주의
일반적인 ‘난리도 아니야’가 모두 이 밈은 아니다. 특정 말투를 재현하는 맥락을 구별하며, 실제 서비스업 종사자나 의료기관 직원을 비하하는 표현으로 확대하지 않는다.
