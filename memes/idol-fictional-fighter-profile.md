# 아이돌 가상 파이터 소개 편집

## 뜻풀이

아이돌 사진에 가상의 선수 소개처럼 과장된 설명을 붙여 꾸미는 이미지 형식이다. 실제 싸움 실력의 순위가 아니라 사진과 그럴듯한 소개 문구를 결합한 허구적 편집을 가리킨다.

## 유래와 확산

2022년 7월 15일 밈과드립은 여러 커뮤니티에서 쓰인 관련 제목과 선수 소개처럼 꾸미는 구성을 설명했다. 글쓴이도 최초 제작자를 모른다고 밝힌다. 해설 한 곳을 확인한 것으로 원사진·편집 이미지는 직접 보지 않았으며 확산 규모나 개별 인물의 능력을 검증한 자료는 아니다.

## 사용 시 주의

외모나 신체를 근거로 실제 사람의 강함·약함을 평가하지 않는다. 굴욕 사진과 특정 인물에 대한 평가 문구를 재현하거나 실제 순위처럼 퍼뜨리지 않는다.
