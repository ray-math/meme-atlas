# 미트스핀 낚시 명칭

## 뜻풀이

링크를 다른 내용인 것처럼 소개해 이용자가 원하지 않는 불쾌한 자료를 접하게 만드는 인터넷 낚시의 역사적 명칭이다. 원영상의 내용이나 성적 세부가 아닌 기만 링크라는 사용 범위만 다룬다.

## 유래와 확산

업데이트 날짜가 2010년 5월 11일인 미주중앙일보 칼럼은 이 명칭을 무관한 명분으로 불쾌한 자료에 유도하는 사례로 설명했다. 칼럼 한 군을 확인했으며 원자료, 음악, 최초 제작자와 유포 규모는 확인하지 않았다.

## 사용 시 주의

타인을 속이는 문구나 실행 방법을 제공하지 않는다. 원콘텐츠나 유해 사이트로 연결하지 않으며 기만적 공유를 장난으로 정당화하지 않는다.
