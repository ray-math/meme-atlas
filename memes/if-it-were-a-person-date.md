# ○○이 사람이라면 사귈 수 있을까

## 뜻풀이

옷·음식·노래처럼 사람이 아닌 대상을 연애 상대라고 가정하고, 그 특징을 성격이나 관계의 모습에 빗대어 취향을 설명하는 질문형 콘텐츠다. 사귈지 말지 고르는 결과보다 그렇게 상상한 이유를 말하는 과정이 중심이다.

- 대상의 분위기를 사람의 성격처럼 풀이한다.
- 같은 대상에 서로 다른 해석을 붙이며 취향을 비교한다.
- 실제 사람의 교제 가능성을 심사하는 질문이나 모든 밸런스게임을 뜻하지는 않는다.

## 유래와 확산

2026년 3월 15일 주간동아는 옷을 사람으로 상상해 교제 가능성을 이야기하는 계정의 콘텐츠를 소개했다. 4월 16일 르데스크는 엔믹스가 노래에, 유튜버 슈기가 음식에 이 질문을 적용한 영상을 각각 소개했다.

확인한 것은 서로 다른 적용 대상을 다룬 두 기사 본문이다. 창작자들의 원게시물이나 영상을 직접 확인한 것은 아니며, 기사에 함께 실린 일반적인 예시를 모두 별개의 실제 제작물로 계산하지 않는다. 각 영상의 최초 공개일, 형식의 최초 창작자와 전체 확산 규모는 확정하지 않는다.

## 사용 시 주의

대상의 특징을 빌린 가상 설정임을 분명히 한다. 실제 사람의 옷차림이나 취향만 보고 성격·연애 행동을 단정하지 않는다. 타인의 외모나 관계 경험을 평가·조롱하거나 답변을 강요하는 방식으로 쓰지 않는다.
