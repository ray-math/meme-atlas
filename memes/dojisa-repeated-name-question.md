# 도지삽니다 반복 응답

## 뜻풀이

직함을 밝히고 상대의 이름을 되묻는 통화 문구를 같은 응답이 되풀이되는 상황으로 옮긴 패러디이다. 실제 긴급전화가 아니라 재편집·모사된 응답 구조를 다룬다.

## 유래와 확산

2011년 12월 30일 노컷뉴스는 통화 문구를 이용한 스마트폰 패러디 앱을 소개하면서 입력 내용과 무관하게 이름을 요구하는 응답이 반복되는 구조를 설명했다. 기사 한 군을 확인했으며 개발자 설명 중 재인용된 보도를 별도 독립 출처로 세지 않는다. 원통화와 앱은 직접 확인하거나 실행하지 않았고 최초 제작자는 확정하지 않는다.

## 사용 시 주의

긴급전화에 장난을 걸거나 직함을 내세워 직원을 압박하는 행동을 따라 하지 않는다. 관련 사건의 책임·정치적 평가를 이 항목의 사실 판정으로 삼지 않는다.
