# 냐아아 도키도키시테타 반복 댓글

## 뜻풀이

일본어 대사의 소리를 한글로 적은 짧은 문구를 캐릭터 반응 이미지와 함께 반복하는 댓글 형식이다. 발음 표기 자체의 번역보다 일정한 문구와 반응을 되풀이하는 사용 방식에 초점을 둔다.

## 유래와 확산

2020년 5월 27일 MEme IS Lief는 문구와 캐릭터 이미지를 붙이는 댓글 관행을 설명했다. 2021년 11월 3일 밈과드립도 반복 댓글과 다른 곳에서의 모방을 소개했다. 해설 두 문서를 확인했지만 같은 계정의 이야기가 겹치므로 독립적인 기원 증명 두 건으로 세지 않는다. 원댓글·애니메이션·움짤은 직접 보지 않았으며 최초 날짜와 댓글 수는 확정하지 않는다.

## 사용 시 주의

반복 게시로 대화를 방해하거나 도배하도록 권하지 않는다. 특정 계정의 신상을 추적하지 않으며 일본어·애니메이션 취향을 비하하는 문맥은 피한다.
