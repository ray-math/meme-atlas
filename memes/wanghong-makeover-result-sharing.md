# 왕홍 분장 변신 콘텐츠

## 뜻풀이

화려한 화장과 가발·의상을 갖춰 왕홍 콘셉트로 변신한 뒤 촬영 과정이나 완성된 모습을 영상·사진으로 공개하는 형식이다. 중국 인플루언서 전체를 가리키는 호칭이나 외모 평가와는 구별한다.

## 유래와 확산

2026년 3월 14일 일간스포츠는 박지윤의 SNS 체험 사진 공개를 보도했다. 같은 달 28일 서울신문은 박명수와 한가인의 채널에서 화장·의상·촬영을 묶은 체험 영상을 공개했다고 설명했다. 두 기사에 겹치는 한가인 사례는 별도 새 사례로 중복 계산하지 않는다. 사진과 영상은 직접 보지 않았으며 최초 기원·정확한 편집 효과·유행 규모는 확정하지 않는다.

## 사용 시 주의

특정 국적이나 민족의 외모를 일반화하거나 비하하는 말로 쓰지 않는다. 화장법 전체나 여행상품 전체를 밈으로 취급하지 않으며 다른 사람의 사진을 허락 없이 재사용하지 않는다.
