# 심즈 고양이 브레이크댄스 패러디

## 뜻풀이

고양이가 사람처럼 춤추는 게임 영상을 바탕으로 춤추는 대상을 다른 캐릭터로 바꾸는 패러디다. 심즈 고양이라는 통칭과 달리 한국어 해설은 사용 게임을 SAKURA School Simulator로 설명한다.

## 유래와 확산

2022년 7월 22일과 8월 6일의 서로 다른 개인 블로그는 인간형 춤을 고양이에 적용한 영상과 여러 캐릭터로 바꾼 사례를 소개했다. 8월 글은 국내 패러디도 설명했다. 두 해설의 문자 설명을 확인했지만 개별 제작자 원문과 영상은 직접 보지 않았다. 음악 추가 순서 설명이 달라 최초 제작자·게시일과 세부 편집 계보는 확정하지 않는다.

## 사용 시 주의

일반 브레이크댄스나 모든 춤추는 동물 영상을 같은 밈으로 묶지 않는다. 실제 동물에게 춤을 강요하는 행동을 권하지 않으며 게임 속 표현과 구별한다.
