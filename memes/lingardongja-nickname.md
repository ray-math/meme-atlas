# 린가동자

## 뜻풀이

축구 선수 린가드를 가리키는 별칭이다. 이름과 애니메이션 제목을 결합한 팬 영상 관련 이름으로 설명되며, 여기서는 영상 전체가 아닌 문자 별칭의 사용을 다룬다.

## 유래와 확산

라이브서울의 2024년 2월 25일 공식 영상 안내는 린가드에게 보내는 영상편지 제목에 이 별칭을 해시태그로 직접 붙였다. 같은 해 2월 4일 개인 블로그의 별명 정리는 린가드와 《구슬동자》를 결합한 말이라고 설명했다. 후자는 개인 요약이므로 최초 제작자나 발생 시점을 확정하는 근거로 쓰지 않는다. 공식 제목의 적용은 확인했지만 원 팬 영상, 노래나 편집 연출을 직접 확인한 것은 아니다. 전체 유행 규모도 미확정이다.

## 사용 시 주의

선수의 실력·성격·국적을 평가하거나 조롱하는 의미를 덧붙이지 않는다. 실제 인물의 정체성과 가상 캐릭터 설정을 혼동하지 않는다.
