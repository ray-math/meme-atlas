# 알아들었으면 끄덕여

## 뜻풀이
상대가 이해했는지 고갯짓으로 확인하라는 드라마 대사를 빌린 표현이다. 단호한 말투를 과장해 응답을 요구하거나 다른 상황의 문구로 바꾸는 패러디에 쓰인다. 단순히 고개를 끄덕이는 모든 행동을 같은 밈으로 묶지 않는다.

## 유래와 확산
[2023년 3월 29일 뉴시스 기사](https://www.newsis.com/view/NISX20230327_0002242289)는 드라마 더 글로리의 대사와 SNL의 더 칼로리 패러디를 함께 소개했다. 이번 확인은 보도 본문에 근거하며 원장면과 패러디 영상을 직접 시청한 것은 아니다.

[2023년 7월 25일 SBS 기사](https://news.sbs.co.kr/news/endPage.do?news_id=N1007281846)는 김영철이 임지연에게 라디오 출연을 요청하는 SNS 문구에 이 대사를 덧붙였다고 전한다. 원래 SNS 게시물은 별도로 열람하지 않았다.

[원룸만들기의 선풍기 상품 페이지](https://oneroommaking.com/product/detail.html?cate_no=1692&display_group=1&product_no=8501)에서도 상품 요약 문구에 같은 표현이 쓰인다. 이 페이지의 최초 게시일은 확인하지 못했다.

서로 다른 재사용 사건의 보도와 상업 페이지의 직접 문구를 확인했다. 최근 1년의 날짜가 확정된 적용 사례나 현재 유행 규모는 이번 자료로 확인하지 않았다.

## 주의
실제 사람에게 명령하면 위압적으로 들릴 수 있다. 상대의 거절을 무시하거나 굴종을 요구하는 말로 사용하지 않으며, 드라마 속 모욕이나 괴롭힘을 현실에서 재연하는 설명으로 확대하지 않는다.
