# 냉무

## 뜻풀이

게시글이나 답글에서 별도 내용이 없음을 알리는 통신어다. 내용 없음을 줄인 표시로 제목 등에 말을 적고 추가 설명을 생략할 때 사용한다.

## 유래와 확산

새국어소식 2002년 1월호는 이 표현의 구성과 게시판 용도를 설명했다. 2022년 5월 20일 에스콰이어 인터뷰에서 구교환은 영상 설명에 이 말을 쓴 이유를 이야기하며 뜻을 풀었다. 당대 언어 해설과 제작자의 사용 자기보고를 구분하며 영상 설명 원페이지와 영상은 직접 보지 않았다. 최초 사용자는 확정하지 않는다.

## 사용 시 주의

설명이 없는 글을 무가치하다고 평가하는 표현으로 권하지 않는다. 모든 빈 게시물을 같은 방식으로 작성한 것으로 간주하지 않는다.
