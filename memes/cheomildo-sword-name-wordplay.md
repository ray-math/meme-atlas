# 쳐밀도

## 뜻풀이

노래 가사의 음절 순서가 뒤바뀐 말을 검 이름처럼 받아들인 팬 말장난이다. 실수한 표현을 물건 이름으로 재해석한 점이 핵심이다.

## 유래와 확산

2010년 10월 18일 TV리포트는 팬들이 해당 글귀를 새긴 모형검을 존박에게 선물했다고 보도했다. 2026년 10월 8일 뉴스1 보도에서는 당사자가 당시 일을 다시 이야기했다. 후자는 과거 일의 회고이지 새로운 패러디 확산의 증거는 아니다. 확인한 것은 기사 본문이며 원무대와 선물 사진은 직접 열람하지 않았다.

## 사용 시 주의

발음 실수를 국적이나 언어 능력에 대한 조롱으로 확대하지 않는다. 당시의 말실수와 팬들의 물건 이름 놀이를 분리해 설명한다.
