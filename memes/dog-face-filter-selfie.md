# 강아지 얼굴 필터 셀카

## 뜻풀이

얼굴에 강아지 코와 혀 같은 효과를 겹쳐 장난스러운 셀카를 만들고 공유하는 형식이다. 필터가 나타내는 얼굴 표정을 흉내 내는 연기 놀이와는 구별한다.

## 유래와 확산

2016년 6월 10일 동아사이언스는 강아지 코와 혀가 붙은 셀카를 소개하며 씨엘의 스냅챗을 출처로 표시했다. 기사 본문과 캡션에서 확인한 사례이며 사진·원게시물이나 앱은 직접 확인하지 않았다. 최초 제작과 국내 참여 규모, 최근 재유행은 확정하지 않는다.

## 사용 시 주의

타인의 얼굴을 동의 없이 변형하거나 놀리는 데 사용하지 않는다. 예전 앱의 기능·정책을 현재 사용법으로 안내하지 않으며 얼굴 정보 제공 여부는 서비스에서 별도로 확인한다.
