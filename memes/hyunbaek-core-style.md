# 현백코어

## 뜻풀이

백화점을 익숙하게 드나들 법한 사람의 무심하고 여유로운 분위기를 옷차림으로 표현하는 스타일 명칭이다. 실제 재산이나 집안 배경을 판별하는 말은 아니다.

## 유래와 확산

MBC 14F의 2026년 10월 12일 영상 소개문은 명칭과 지향하는 분위기를 설명한다. 마리끌레르 코리아의 11월 기사에서는 에디터가 해당 스타일을 직접 따라 입었다고 서술한다. 페이지의 표시일은 11월 4일이고 별도 기계 시간은 11월 6일로 나타나므로 둘을 같은 게시 시점으로 단정하지 않는다. 확인한 것은 설명문과 에디터의 재현 자기보고이며, 영상·사진의 구현은 직접 검증하지 않았다.

## 사용 시 주의

부유함을 인격이나 능력의 우열로 보거나 고가품 구매를 권하는 표현으로 쓰지 않는다. 특정 브랜드 소유가 필수라고 단정하지 않으며, 정확한 조어 과정과 최초 창작자는 확인하지 않았다. 지향하는 이미지 일반을 뜻하는 ‘추구미’보다 특정한 스타일 명명에 초점이 있다.
