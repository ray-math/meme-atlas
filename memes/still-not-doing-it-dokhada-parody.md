# 이래도 안 ○○? 독하다 독해

## 뜻풀이

어떤 행동을 하지 않는 상대에게 이유를 되묻는 문장 뒤에 ‘독하다 독해’를 붙여 끈질기게 버틴다는 식으로 과장하는 말틀이다. 여기서는 만화 이미지에 대상과 문구를 바꾸어 붙인 국내 활용 범위를 다룬다.

## 유래와 확산

한국경제의 2026년 6월 18일 보도는 기업 로고를 단 만화 캐릭터가 매수하지 않는 사람을 향해 이 문구를 말하는 합성 이미지를 소개했다. 한경매거진의 2026년 8월 9일 기사도 같은 구체 사례를 설명했다. 이는 두 기사에서 확인한 한 제작 사례이며, 서로 독립된 이미지 두 건으로 세지 않는다. 원게시물이나 이미지를 직접 확인하지 않았고 원작 장면의 출처, 최초 변형과 유행 규모는 확정하지 않는다. 기사에 함께 실린 시세·전망은 이 항목의 근거 범위에서 제외한다.

## 사용 시 주의

누군가에게 투자나 소비를 재촉하는 근거가 아니다. 상대의 거절과 선택을 존중하며, 실제 위협·괴롭힘이나 손실을 조롱하는 데 사용하지 않는다.
