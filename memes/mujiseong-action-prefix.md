# 무지성 ○○

## 뜻풀이

충분히 따져 보지 않고 어떤 행동을 한다는 뜻을 강조할 때, 행동을 나타내는 말 앞에 ‘무지성’을 붙이는 표현이다. 온라인에서는 무작정 행동하는 모습을 과장하거나 자신의 선택을 자조하는 말로 쓰인다.

## 유래와 확산

2022년 3월 머니투데이는 이 표현을 신조어로 풀이하면서 ‘무지성 영끌’과 ‘무지성 추매’ 같은 결합형을 기사에서 사용했다. 같은 해 6월 이투데이 칼럼도 온라인 신조어와 밈으로 설명하고 별도의 문맥에 적용했다.

두 매체의 본문은 같은 어휘가 다른 행동을 나타내는 말과 결합하는 방식을 보여 준다. 정확한 최초 발생 연도나 특정 작품에서 시작됐다는 유래, 정치적 확산 경로는 이 항목에서 확정하지 않는다. 2022년 자료로 확인한 역사적 표현이며 최근 1년의 신규 유행이라는 뜻은 아니다.

## 사용 시 주의

실제 지능이나 장애를 판단하는 말이 아니다. 다른 사람을 무능하다고 낙인찍기보다 행동의 맥락을 구체적으로 설명하는 편이 낫다. 기사에 등장한 투자 결합형은 언어 용례일 뿐 투자 조언이 아니다.
