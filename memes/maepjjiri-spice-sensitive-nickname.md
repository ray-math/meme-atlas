# 맵찔이

## 뜻풀이

매운 음식을 잘 먹지 못하는 사람을 장난스럽게 부르는 말이다. 스스로의 음식 취향이나 반응을 설명하는 별명으로도 쓴다.

## 유래와 확산

iMBC의 2023년 6월 19일 라디오 보도에서는 출연자가 자신을 이렇게 부르며 매운 음식을 못 먹는다고 설명했다. 같은 매체의 2026년 2월 6일 다른 프로그램 예고에서도 출연자를 꾸미는 말로 사용했다. 서로 다른 프로그램의 문자 용법이지만 두 기사는 같은 매체이며, 뒤 자료는 방영 완료 기록이 아닌 예고다.

## 사용 시 주의

낮춰 부르는 어감이 있으므로 상대가 싫어하면 사용하지 않는다. 매운 음식 섭취를 강요하거나 건강 상태를 추정하는 말로 쓰지 않는다. 매운맛에 대한 자신감을 뜻하는 맵부심과는 구분한다. 최초 유래와 확산 규모는 미확정이다.
