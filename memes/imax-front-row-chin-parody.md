# 턱디세이 아이맥스 앞줄 과장사진

## 뜻풀이

아이맥스관 앞줄에서는 인물의 턱이 유난히 크게 보인다는 식으로 얼굴 비율을 과장한 이미지 농담. 실제 관람 화면의 정확한 모습이라기보다 앞자리 시야에 대한 우스갯소리를 시각화한 형식이다.

## 유래와 확산

2026년 8월 21일 YTN 보도는 여러 영화 인물의 턱을 강조한 이미지가 공유되는 현상을 소개했다. 동시에 기자의 현장 관찰에서는 인터넷 밈만큼 과도한 왜곡이 없었다고 설명했다. 보도 한 군에 근거하며 원이미지·영상이나 실제 극장 시야를 직접 검증하지 않았다. 같은 기사에 나온 여러 별칭을 별개의 밈으로 늘려 세지 않는다.

## 사용 시 주의

특정 배우의 외모를 평가하거나 타인의 얼굴을 무단으로 변형하는 용도로 쓰지 않는다. 과장된 사진을 좌석 선택의 사실 자료로 제시하지 않으며 원저작물의 이미지를 그대로 재배포하지 않는다.
