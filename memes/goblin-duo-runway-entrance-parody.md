# 도깨비 두 사람 등장 패러디

## 뜻풀이

두 사람이 나란히 비장하게 걸어오며 드라마 도깨비의 등장 장면을 재현하는 형식이다. 원작 분위기를 다른 출연자나 상황으로 옮기며 날씨를 나열하는 대사 말틀과는 구별한다.

## 유래와 확산

2017년 3월 23일 iMBC는 김과장이 도깨비를 패러디해 두 인물이 안개와 역광 속에서 나란히 걸어오는 장면을 촬영·방송했다고 설명했다. 2026년 10월 12일 스포츠동아는 공개된 미스터트롯4 티저에서 안성훈과 김용빈이 함께 걸어오고 도깨비 OST가 더해진 구성을 보도했다. 서로 다른 드라마 장면과 공개 티저의 두 제작 사례이며 원영상은 직접 보지 않았다. 티저 공개를 프로그램 본방송 완료로 취급하지 않는다.

## 사용 시 주의

단순히 두 사람이 걷는 모든 장면을 같은 패러디로 분류하지 않는다. 위험한 소품이나 대치 상황을 재현하도록 안내하지 않으며 원음악 가사·영상은 옮기지 않는다.
