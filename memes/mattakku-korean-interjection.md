# 마따끄

## 뜻풀이

일본어 감탄 표현을 장난스럽게 한글로 옮겨, 어이없거나 뜻대로 되지 않는 상황에 ‘정말이지’ 같은 느낌으로 쓰는 문자 반응. 표준적인 일본어 표기나 모든 캐릭터의 고정 대사를 뜻하지는 않는다.

## 유래와 확산

2024년 2월 15일 공개 블로그 글은 일상 계획이 어긋난 이야기를 시작하며 이 표현을 직접 사용했다. 2025년 9월 17일 게임 커뮤니티 해설은 한국어 표기와 감탄·불만의 쓰임을 설명했다. 실제 일상 글과 사용 해설을 구분하며 특정 캐릭터가 최초 기원이라는 주장이나 전파 규모는 확정하지 않는다. 원음성과 이미지는 직접 확인하지 않았다.

## 사용 시 주의

일본어 발음이나 특정 문화권 사람을 희화화하는 표현으로 확대하지 않는다. 친근한 투덜거림도 상대에게는 핀잔처럼 들릴 수 있으며, 사용자의 사적인 일화나 이미지를 그대로 재배포하지 않는다.
