# I can see 엉뚱한 해석

## 뜻풀이

영어 I can see를 단어별로 엉뚱하게 이어 나는 할 수 있는가 보다로 읽는 말장난이다. 원래의 영어 뜻 대신 자신감이나 응원 문장으로 바꾸어 쓰는 형식이며 올바른 번역을 설명하는 표현은 아니다.

## 유래와 확산

하자센터는 2023년 여름 캠프 안내에서 이 말장난을 캠프명과 설명에 사용했다. 안내된 행사 기간은 7월 31일부터 8월 4일이며 게시일은 따로 확인하지 않았다. 한국농어촌공사 홈페이지의 2024년 9월 27일 표시 게시문은 주어를 나·너·우리로 바꾸어 응원에 활용한다. 두 기관의 문자 사용을 확인했지만 최초 창작자와 최근 재유행은 확정하지 않는다.

## 사용 시 주의

실제 영어 학습에서 정확한 번역으로 제시하지 않는다. 영어 능력이 부족한 사람을 비웃거나 행사 참가자의 개인 정보를 예시로 사용하지 않는다.
