# 말씀 중에 죄송합니다

## 뜻풀이

손웅정의 인터뷰에서 나온 단호한 정정 말투를 따라 하는 밈이다. 상대의 칭찬을 끊는 도입부와 월드클래스가 아니라는 답변이 연결되며, 답변을 긍정하거나 화자 자신을 칭찬하는 쪽으로 바꾼 편집도 있다.

## 유래와 확산

2022년 6월 MBC는 2018년 손웅정 인터뷰가 다시 화제가 되며 여러 패러디 영상으로 이어졌다고 보도했다. 같은 달 조선일보 기사에는 부정적인 답변을 긍정형이나 자기 칭찬으로 바꾼 편집 사례가 소개됐다.

확인한 것은 2018년 인터뷰를 소재로 한 2022년 재유행 보도다. 인터뷰 원영상과 개별 편집 영상은 직접 시청하지 않았으며, 최초 패러디 게시일이나 전체 확산 규모는 확정하지 않는다. 일반적인 사과나 말 끊기 표현 전체가 아니라 이 인터뷰의 말투와 답변 편집 계열을 다룬다.

## 사용 시 주의

편집된 답변을 실제 발언처럼 인용하지 않는다. 운동선수나 가족의 인격을 평가하는 말로 확대하거나, 대화 상대를 계속 끊는 행동을 정당화하는 데 쓰지 않는다.
