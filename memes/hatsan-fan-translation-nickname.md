# 핫산 — 팬 번역 참여자 호칭

## 뜻풀이

게임 등의 비공식 번역이나 검수에 참여하는 사람이 자신이나 동료를 장난스럽게 부르는 인터넷 호칭이다. 팬 번역 작업의 별칭만 다루며 실제 국적·직업·보수 수준을 뜻하는 말로 일반화하지 않는다.

## 유래와 확산

날짜가 ‘26. 4. 10.’으로 표시된 게임제너레이션 글은 팬 번역 인력과 자칭 용법을 설명했다. 2025년 5월 12일 록맨 에그제 커뮤니티 글에서도 작성자가 자신을 번역 핫산이라고 소개하며 작업 상황을 전했다. 해설 한 군과 실제 자칭 게시물 한 군을 확인했으며 연결된 모집 글 미리보기를 별도 사용군으로 세지 않는다. 해설의 역사 복원 한계와 AI 분석 활용 고지를 고려해 기원 연도·원작 설명은 채택하지 않았다.

## 사용 시 주의

무급 노동을 당연하게 여기거나 번역자에게 작업을 강요하는 말로 쓰지 않는다. 민족 고정관념을 수용하지 않으며 연결 파일·프로그램이나 번역 성과는 검증하지 않았다.
