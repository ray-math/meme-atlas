# 무수히 많은 요청이

## 뜻풀이

누군가에게 특정한 요청이 잇따르는 상황을 과장해 나타내는 말틀이다. ‘악수’ 자리에 사진 촬영이나 예약처럼 다른 행동을 넣어 인기가 많거나 요청이 몰리는 모습을 표현한다.

## 유래와 확산

2022년 8월 인벤 기사는 사진 요청으로 바꾼 표현을 사용했다. 개인 블로그의 퍼스널 컬러 체험기에서는 예약 요청으로 바꾼 소제목과 예약이 어려웠다는 맥락을 확인할 수 있다.

서로 다른 글의 문자 활용에 근거하며 원짤과 영상은 직접 확인하지 않았다. 블로그 표시일은 2022년 6월 23일이지만 본문에 그 뒤 날짜가 언급돼 문구의 최초 작성일로 확정하지 않는다. 원래 악수 표현의 기원이나 널리 퍼진 정도는 단정하지 않는다.

## 사용 시 주의

과장된 문구를 실제 예약 수나 인기도의 통계처럼 사용하지 않는다. 특정인에게 접촉이나 사진 촬영을 요구할 권리가 있다는 뜻으로 쓰지 않는다.
