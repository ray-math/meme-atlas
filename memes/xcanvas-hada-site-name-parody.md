# 엑스캔버스하다 이름 치환

## 뜻풀이

엑스캔버스하다라는 광고 표현의 브랜드 이름을 다른 이름으로 바꾸어 소개 문구를 만드는 차용이다. 일반적인 명사와 하다의 결합 전체를 밈으로 보는 것은 아니다.

## 유래와 확산

2006년 12월 26일 ZDNet Korea는 유머사이트가 광고 표현을 주인장닷컴하다로 바꾸어 자체 소개에 사용했다고 설명했다. 특정 사이트의 한 차용을 보도한 문서이며 원사이트와 광고는 직접 열람하지 않았다. 최초 제작 시점이나 광범위한 유행으로 확대하지 않는다.

## 사용 시 주의

당시 광고의 효과나 상품 성능을 보증하지 않는다. 확인한 이름 치환 밖의 모든 비슷한 표현을 같은 계보로 단정하지 않는다.
