# 꽈찌쭈 대사 소리표기

## 뜻풀이

드라마 《로스트》의 한국어 대사를 들리는 소리에 가깝게 적어 인용하는 문자 패러디이다. ‘꽈찌쭈’라는 표기와 관련 대사 변형을 다루며 배우나 작품 전체를 뜻하는 항목은 아니다.

## 유래와 확산

2011년 6월 29일 SBS 보도는 드라마 대사의 발음표기가 패러디로 쓰이고, ‘꽈찌쭈’가 별명으로도 사용되었다고 설명했다. 당시 보도의 사용 설명을 확인한 것으로 원드라마와 개별 패러디 이미지는 직접 확인하지 않았다. 최초 작성자와 전체 확산 규모는 확정하지 않는다.

## 사용 시 주의

배우·교포·외국인의 한국어 능력을 낮춰 평가하는 용도로 쓰지 않는다. 실제 사람에게 별명을 강요하거나 억양을 조롱하는 예시는 제외하며, 비표준 표기를 올바른 한국어 표기라고 소개하지 않는다.
