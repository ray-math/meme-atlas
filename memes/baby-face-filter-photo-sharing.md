# 아기 얼굴 필터 인증샷

## 뜻풀이

성인의 현재 얼굴을 아기처럼 바꾼 필터 결과를 공유하며 평소 모습과 대비시키는 사진 놀이이다. 실제 어린 시절 사진이나 자녀의 얼굴 예측과는 다르다.

## 유래와 확산

2019년 5월 28일 에스콰이어는 소유진이 공개한 백종원의 필터 사진과 박나래의 별도 게시 등 여러 성인의 적용 사례를 소개했다. 하나의 매체가 설명한 복수 게시 사례로 범위를 제한한다. 원본 사진을 직접 감상하거나 필터를 실행하지 않았으며 최근 재유행이나 현재 앱 기능을 확인한 것은 아니다.

## 사용 시 주의

다른 사람의 얼굴을 가공·공개하기 전 동의를 구한다. 외모 순위나 비하에 이용하지 말고 결과물을 실제 유년 모습처럼 전달하지 않는다. 이미지·필터의 이용 조건도 별도로 확인한다.
