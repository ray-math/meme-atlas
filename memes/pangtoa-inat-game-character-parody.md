# 빵뚜아 이낫 게임 캐릭터 패러디

## 뜻풀이

축구 게임 속 린가드 모델을 가상의 별도 캐릭터로 꾸미고 다른 팀에 배치하거나 대결시키는 팬 패러디. 실제 선수의 신원이나 이적 사실이 아니라 게임 안에서 만든 설정을 가리킨다.

## 유래와 확산

2020년 6월 22일 XERIES 제작 글은 ‘빵뚜아 이낫’이라는 이름으로 PES2020의 린가드 모델을 변형하고 울산 팀에 배치했다고 설명했다. 다른 제작 영상의 썸네일을 사용했다는 출처 설명과 두 캐릭터 팀을 대결시키는 영상 제목도 확인된다. 제작자 자기보고 한 건에 한정하며 게임 화면이나 연결 영상을 직접 확인하지 않았다. 최초 댓글·창작자와 확산 규모는 확정하지 않는다.

## 사용 시 주의

실제 선수의 국적이나 외모를 조롱하는 설정으로 확대하지 않는다. 가상의 게임 캐릭터와 실제 인물의 소속·경력을 구분하고, 원본 영상의 이용 허락이 모든 재배포까지 허용한다는 뜻으로 받아들이지 않는다.
