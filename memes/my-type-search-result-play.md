# MY TYPE 검색 결과 놀이

## 뜻풀이

SNS에서 MY TYPE을 검색한 뒤 생일 숫자로 정한 순번의 결과를 자신의 이상형처럼 소개하고 공유하는 놀이이다. 예상 밖의 인물이나 캐릭터가 나오는 결과를 재미로 받아들이는 형식이다.

## 유래와 확산

대학내일의 2025년 5월 26일 글은 생일 숫자를 더해 게시물 순서를 정하고 결과를 공유하는 구체적인 사용 방식을 설명한다. 해설 한 군을 확인했으며 원게시물이나 영상은 직접 열람하지 않았다. 2026년 11월 기준 최근 1년 밖의 사례로, 최초 발생과 전체 사용 규모는 확정하지 않는다.

## 사용 시 주의

검색 결과는 심리검사나 실제 호감의 증거가 아니다. 결과에 나온 사람의 외모를 모욕하거나 자신의 취향을 타인에게 강요하지 않는다.
