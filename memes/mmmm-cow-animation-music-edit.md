# mmmm cow

## 뜻풀이

애니메이션의 젖소 오티스가 다른 인물 뒤에서 익살스러운 자세를 취하는 장면에 음악을 결합한 편집영상이다. 이 항목은 특정 장면과 음악의 조합만 다루며 모든 젖소 춤을 같은 형식으로 묶지 않는다.

## 유래와 확산

2021년 6월 2일 한국어 해설은 《신나는 동물농장》 장면과 Alice DJ의 음악을 조합한 영상 형식을 설명한다. 해설 본문은 확인했지만 원영상과 변형 영상을 직접 재생하지 않았으므로 최초 업로드와 확산 규모는 확정하지 않는다. 표제의 ‘mmmm’가 무엇에서 유래했는지도 자료의 추측을 사실로 채택하지 않았다.

## 사용 시 주의

원작 영상과 음악의 권리를 구별한다. 특정 편집영상의 설명을 작품 전체의 내용이나 제작 의도로 확대하지 않는다.
