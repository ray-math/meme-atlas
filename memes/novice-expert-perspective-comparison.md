# 하수·고수 비교 말틀

## 뜻풀이

같은 상황에 대한 두 해석을 ‘하수’와 ‘고수’로 나란히 적고 뒤쪽에 다른 관점이나 뜻밖의 반전을 놓는 비교 말틀이다. 실제 숙련도를 측정하는 분류라기보다 글쓴이가 관점 차이를 강조하는 구조다.

## 유래와 확산

2026년 5월 25일 계정 화면에 대한 해석을 비교한 게시물과 7월 21일 게임 제휴 소식을 바라보는 관점을 뒤집은 게시물의 텍스트를 확인했다. 같은 플랫폼의 서로 다른 두 게시판 사례이며 실제 작성자의 인적 독립성은 확인하지 않았다. 두 사례만으로 최초 제작자나 보편적 유행 규모를 단정하지 않는다.

## 사용 시 주의

다른 사람의 실제 능력이 열등하다는 근거로 사용하지 않는다. 원게시물의 정치 구호·욕설·기업 평가는 채택하지 않으며 두 관점을 병치하는 형식만 설명한다.
