# 엄준식 이름 반복 댓글

## 뜻풀이

인터넷 방송인의 이름을 대화 내용과 무관하게 반복해 쓰는 댓글 관행을 가리킨다. 맥락을 아는 사람들끼리 통하는 장난으로 소비되기도 했지만 반복 게시가 대화를 방해하고 불쾌감을 준다는 비판도 받았다.

## 유래와 확산

2020년 6월 6일 남정미 기자의 기사에는 해당 이름이 다른 방송에서도 반복돼 쓰이고 부정적인 반응을 얻었다는 설명이 나온다. 이 항목은 보도 한 군의 역사적 문자 사용 설명에 한정한다. 원채팅·방송을 직접 확인하지 않았으며 기사 당시의 유행 평가를 영구적인 결론으로 채택하지 않는다.

## 사용 시 주의

개인의 사생활이나 이름 노출 경위를 추적하지 않는다. 금칙어를 피하는 방법이나 반복 게시 예문을 제공하지 않으며 채팅 방해와 괴롭힘을 권하지 않는다.
