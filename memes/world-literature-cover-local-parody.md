# 세계문학전집 표지 패러디

## 뜻풀이

익숙한 세계문학전집 표지의 색 띠와 글자 배치를 떠올리게 하면서 제목·저자명·그림을 다른 주제로 바꾸는 이미지 패러디다. 실제 출판된 책이나 출판사와의 정식 협업 상품이라는 뜻은 아니다.

## 유래와 확산

2026년 이너부스 해설은 민음사와 오늘의 귀여움 협업 표지와 이를 다시 응용한 고양시 SNS 콘텐츠를 구분해 소개한다. 고양시의 지역명과 고양이 말투를 제목·저자명에 넣은 사례가 설명된다. 민음사 공식 페이지에서도 캐릭터 표지 협업을 확인했다. 이너부스의 업데이트 날짜는 접근 결과에 따라 9월 11일과 10월 21일로 달라 최초 게시일을 확정하지 않는다. 고양시 원 SNS 게시물·이미지와 제작일은 직접 검증하지 않았다.

## 사용 시 주의

표지 디자인과 그림의 권리를 확인해야 하며 특정 패러디 사례가 자유로운 상업 이용 허락을 뜻하지 않는다. 가상의 표지를 실제 책·공식 협업으로 오인시키지 않는다.
