# 마 갱기에 집중 안하나

## 뜻풀이

야구 경기 이외의 내용으로 시선을 끈 뒤 경기에 집중하라는 문구를 보여주는 낚시·반응 형식이다. ‘마갱집’으로 줄여 부르며 선수 사진과 결합하는 방식으로 설명된다.

## 유래와 확산

2023년 6월 6일 야구 밈 해설은 관심을 끄는 제목으로 독자를 유도한 뒤 선수 사진과 집중 요구 문구를 배치하는 방식을 소개했다. 확인 범위는 해설 한 건이며 사진·영상이나 원게시물은 직접 보지 않았다. 실제 선수의 발언·어린 시절 일화·최초 제작자는 확인하지 않는다.

## 사용 시 주의

실제 관중에게 공격적으로 소리치거나 지역 말투를 조롱하는 용도로 쓰지 않는다. 사진 속 인물이 실제로 한 말인 것처럼 전달하지 않으며 선수 전체를 가리키는 별명으로 확대하지 않는다.
