# 그것이 약속이니까

## 뜻풀이

무엇을 하겠다고 말한 뒤 구체적인 이유 대신 약속이라는 결론을 되풀이하는 말틀이다. 진지한 설명처럼 들리지만 앞선 말을 반복하는 데서 웃음을 만들며 대상이나 결론을 바꾸어 같은 화법을 흉내 낸다.

## 유래와 확산

2020년 7월 서울신문은 고이즈미 신지로의 말투를 흉내 내는 패러디를 설명했다. 같은 달 SBS 칼럼은 약속 이행과 관련한 서로 다른 국내 사건에서 이 문구가 쓰인 맥락을 소개하고 제목과 본문에서도 인용했다.

독립 매체의 설명 두 군과 칼럼 자체의 인용에 근거한다. 원게시물과 영상은 직접 확인하지 않았으며 인터넷에서 유통된 모든 어록을 실제 발언으로 간주하지 않는다. 정확한 원어 번역, 최초 제작자, 인물 전체에 대한 평가를 확정하지 않는다. 인물 별명 아래 묶이는 다른 모든 패러디까지 포괄하지 않는다.

## 사용 시 주의

화법을 설명하는 것과 정치인의 실제 능력이나 사건의 사실관계를 판단하는 것을 구분한다. 실제 약속을 회피하거나 상대의 정당한 설명 요구를 무시하는 데 쓰지 않는다.
