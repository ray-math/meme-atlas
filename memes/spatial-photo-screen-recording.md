# 입체 사진 화면녹화 공유

## 뜻풀이

사진 속 피사체와 배경에 깊이감이 생겨 입체적으로 움직이는 효과를 화면 녹화해 공유하는 사진 놀이이다. 정지 사진을 그대로 올리는 대신 시점이 움직이는 듯한 변화를 보여주는 형식이다.

## 유래와 확산

코스모폴리탄의 2026년 2월 4일 본문은 휴대전화의 공간 장면 효과를 화면 녹화로 공유하는 유행을 설명한다. 기사 한 군의 사용 방식 설명을 확인했으며 개별 제작자의 영상이나 기기의 기능을 직접 실행하지 않았다. 특정 기종과 소프트웨어의 현재 지원 여부, 처리 성능을 보장하지 않는다.

## 사용 시 주의

타인의 사진을 동의 없이 가공·공유하지 않는다. 실제 현장을 입체 촬영한 기록과 정지 사진에 적용한 효과를 구별하며 사진 속에 없던 깊이 정보를 사실로 단정하지 않는다.
