# 표제어

**형태·문법적 성격** 표현 / 명사 / 영상 형식 등 확인 가능한 범위만  
**사용역** 비격식 / 장난 / 조롱 / 자조 등  
**관련 표기** 출처로 확인된 원어·변형만

## 뜻풀이
**1.** 처음 보는 사람도 이해할 수 있는 간결한 정의.


**2.** 의미가 실제로 구분될 때만 추가.


뜻의 분류가 편집상 구분이면 그렇게 표시한다.

## 실제 용례
- **게시일 · 작성자/매체 · 플랫폼 · 대응 의미**
  > 직접 확인한 짧은 원문 인용.
  [원문](https://example.com) · 영상이면 구간 · 확인일: YYYY-MM-DD.
  맥락과 뉘앙스를 편집자의 말로 설명한다.

서로 독립된 작성자·플랫폼·상황에서 모은 용례를 비교한다. 미확인 영상이나 2차 자료에만 등장하는 예시는 검증 대기 목록으로 분리하고, 예문을 창작하여 채우지 않는다.

## 사용 설명
누가 누구에게, 어떤 상황에서 쓰는가? 비슷한 말과 무엇이 다른가? 호의·조롱 등 뉘앙스와 오용 가능성을 설명한다. 단정적인 사용 빈도·인기도는 근거 없이 쓰지 않는다.

## 유래와 확산
최초 원본, 나중의 확산, 재유행을 구분한다. 모르는 기원은 미확인으로 남긴다.

## 기록과 근거
- 최초 원본·게시일: 확인 내용 또는 미확인.
- 보도·관찰일: YYYY-MM-DD. 월별 색인은 이 날짜를 기준으로 한다.
- 검증 수준: 원본 확인 / 2차 설명 확인 / 검증 대기.
- 마지막 확인: YYYY-MM-DD.
- 출처: [제목](https://example.com) · 어떤 사실을 뒷받침하는지와 확인 범위.
